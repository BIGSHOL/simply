|---|------|------|
| 1 | 목표 | AdSense 부업 수익 창출을 위한 AI 심리테스트 플랫폼 |

## 1. 문제 정의

### 1.1 현재 상황 (As-Is)

기존 심리테스트 사이트들은 마치 10년 전에 만들어진 것처럼 낡은 디자인에, 누가 해도 비슷비슷한 결과만 나옵니다. "당신은 ENFP입니다" 한 줄로 끝나는 성의 없는 결과에 광고가 덕지덕지 붙어있어 사용자들이 금방 이탈합니다.

### 1.2 목표 상황 (To-Be)

AI가 사용자의 답변을 분석해서 정말 "나만을 위한" 것 같은 풍부하고 재치있는 결과를 제공합니다. 깔끔한 디자인에 적절한 광고 배치로 사용자 경험과 수익을 모두 잡습니다. 결과가 재미있어서 친구들에게 공유하고 싶어지는 서비스.

### 1.3 왜 지금인가? (Why Now)

- AI API가 저렴해지고 품질이 좋아짐
- 기존 심리테스트 시장은 레거시가 대부분
- MZ세대의 "나를 알아가는 콘텐츠" 수요 지속
- 부업/사이드 프로젝트로 적절한 규모

## 2. 사용자 페르소나

### 2.1 주요 페르소나

| 항목 | 페르소나 A | 페르소나 B | 페르소나 C |
|------|-----------|-----------|-----------|
| 이름/별칭 | "심심한 민지" | "점심시간 준호" | "퇴근길 수연" |
| 나이/직업 | 17세 고등학생 | 22세 대학생 | 28세 직장인 |
| 핵심 니즈 | 친구들과 공유할 재미난 거리 | 수업 쉬는 시간에 심심풀이 | 퇴근 후 가벼운 힐링 |
| 불편 포인트 | 기존 테스트는 다 해봐서 새로운 게 없음 | 결과가 너무 짧고 재미없음 | 광고가 너무 많아서 짜증남 |
| 사용 상황 | 쉬는 시간, 집에서 | 강의 쉬는 시간, 카페 | 퇴근길 지하철, 집 침대 |

### 2.2 페르소나의 하루 (시나리오)

**민지의 하루:**
점심시간, 민지는 친구들과 밥을 먹다가 "야 이거 해봐 진짜 웃겨" 하며 카톡으로 링크를 공유받습니다. 테스트를 해보니 AI가 분석한 결과가 너무 웃기고 공감돼서 캡처해서 인스타 스토리에 올립니다. 그걸 본 다른 친구들도 "나도 해봐야지" 하며 링크를 타고 들어옵니다.

## 3. 사용자 스토리

### FEAT-0: 공통 흐름 (비로그인)
- [x] 사용자로서, 로그인 없이 바로 테스트를 시작할 수 있어야 한다. 왜냐하면 가입은 귀찮고 빠르게 해보고 싶으니까.
- [x] 사용자로서, 결과 페이지 링크를 공유할 수 있어야 한다. 왜냐하면 친구들에게 내 결과를 보여주고 싶으니까.

### FEAT-1: AI 심리테스트 (MVP)
- [ ] 사용자로서, 다양한 카테고리의 테스트 목록을 볼 수 있어야 한다. 왜냐하면 내 관심사에 맞는 테스트를 찾고 싶으니까.
- [ ] 사용자로서, 테스트 질문에 답하면 AI가 분석한 개인화된 결과를 받을 수 있어야 한다. 왜냐하면 뻔한 결과가 아닌 "나만의" 결과를 원하니까.
- [ ] 사용자로서, 결과를 이미지로 저장하거나 링크로 공유할 수 있어야 한다. 왜냐하면 SNS에 올리거나 친구에게 보내고 싶으니까.

### FEAT-2: 테스트 추천/인기 순위 (v2)
- [ ] 사용자로서, 인기 테스트 순위를 볼 수 있어야 한다.
- [ ] 사용자로서, 새로 올라온 테스트를 확인할 수 있어야 한다.

### FEAT-3: 다양한 테스트 카테고리 (v2)
- [ ] 사용자로서, 연애/성격/MBTI/직업 등 카테고리별로 테스트를 탐색할 수 있어야 한다.

## 4. 성공 지표

### 4.1 노스스타 지표 (결과 지표)
| 지표명 | 정의 | 목표치 | 측정 주기 |

|--------|------|--------|

| 공유 전환율 | 결과 본 사람 중 공유한 비율 | 20% 이상 |
| 일일 방문자 수 | 일일 순 방문자 | 3,000명/일 |

## 5. 범위 관리

### 5.1 MVP (반드시 포함)
- FEAT-1: AI 심리테스트 (1개 테스트로 시작)
- FEAT-0: 비로그인 사용, 결과 공유
- AdSense 광고 연동
- 모바일 우선 + PC 버전

### 5.2 옵션 (시간 허용 시)
- 테스트 2~3개 추가
- 인기 순위 표시
- 카테고리 분류

### 5.3 Non-goals (명시적 제외)
- 회원가입/로그인 기능 - 진입 장벽 최소화
- 프리미엄 유료화 - AdSense만으로 수익화
- 테스트 직접 제작 기능 - 운영자가 직접 추가
- 다크 모드 - v2에서 고려
- 앱 (PWA 포함) - 웹 우선

## 6. 가정과 리스크

### 6.1 핵심 가정
| # | 가정 | 검증 방법 |
|---|------|----------|
| 1 | AI 결과가 기존 테스트보다 만족도가 높을 것 | 주변 지인 피드백 |
| 2 | 사용자들이 결과를 SNS에 공유할 것 | 공유 버튼 클릭률 측정 |
| 3 | 광고 수익이 AI API 비용을 상회할 것 | 비용/수익 모니터링 |

### 6.2 Top 5 리스크 보드

| # | 가정 | 리스크 | 완화 | 트리거 | 대응 |
|---|------|--------|------|--------|------|
| 1 | API 비용 < 수익 | AI API 비용 초과 | 결과 캐싱, 호출 최적화 | 비용 > 수익의 50% | 캐싱 강화, 모델 변경 |
| 2 | 높은 공유율 | 공유가 안 됨 | 공유 버튼 눈에 띄게 | 공유율 < 5% | 공유 인센티브 추가 |
| 3 | 빠른 로딩 | AI 응답 느림 | 스트리밍 응답, 로딩 UI | 응답 > 10초 | 사전 생성, 캐싱 |
| 4 | 트래픽 유입 | 방문자 없음 | SEO 최적화, SNS 공유 | DAU < 100 | 마케팅 채널 확대 |
| 5 | 광고 승인 | AdSense 미승인 | 콘텐츠 품질 확보 | 2주 내 미승인 | 다른 광고 네트워크 |

## 7. 해결 가설과 실험

### 7.1 가설
> 만약 AI가 개인화된 재치있는 결과를 제공하면, 사용자들이 결과를 SNS에 공유할 것이다. 왜냐하면 "나만의" 특별한 결과는 자랑하고 싶은 욕구를 자극하기 때문이다.

### 7.2 실험 루프

```
실험 → 관측 → 학습 → 다음 가설
```

| 단계 | 내용 |
|------|------|
| 실험 | 테스트 1개로 MVP 출시, 지인 10명에게 공유 |
| 관측 | 완료율, 공유율, 재방문율 측정 |
| 학습 | 공유율 20% 이상이면 성공 |
| 다음 | 테스트 추가 vs 기존 테스트 개선 결정 |
