# User Flow (사용자 흐름도)

> Mermaid 플로우차트로 핵심 기능의 주요 여정을 표현합니다.
> 성공/실패 분기를 포함하고, 비로그인 기반의 간단한 흐름입니다.

---

## MVP 캡슐

| # | 항목 | 내용 |
|---|------|------|
| 1 | 목표 | AdSense 부업 수익 창출을 위한 AI 심리테스트 플랫폼 |
| 2 | 페르소나 | 10~30대 (중고등학생, 대학생, 직장인) |
| 3 | 핵심 기능 | FEAT-1: AI 심리테스트 (개인화된 결과 생성) |
| 4 | 성공 지표 (노스스타) | AdSense 월 수익 |
| 5 | 입력 지표 | 테스트 완료율, 공유 전환율 |
| 6 | 비기능 요구 | 빠른 로딩 속도 (3초 이내) |
| 7 | Out-of-scope | 프리미엄 유료화, 소셜 로그인, 회원가입 |
| 8 | Top 리스크 | AI API 비용이 수익보다 높아질 수 있음 |
| 9 | 완화/실험 | 결과 캐싱, API 호출 최적화, 비용 모니터링 |
| 10 | 다음 단계 | MVP 개발 시작 - 테스트 1개로 검증 |

## 1. 전체 사용자 여정 (Overview)

```mermaid
graph TD
    A[앱 진입] --> B[메인 화면<br/>테스트 목록]

    C --> D[테스트 진행<br/>질문 답변]
    D --> E[AI 결과 생성<br/>로딩 화면]
    E --> F{성공?}

    F -->|No| H[에러 안내]
    H --> D
    G --> I{공유?}
    I -->|Yes| J[SNS/링크 공유]
    I -->|No| K[다른 테스트 보기]
    J --> K
    K --> B
```

## 2. FEAT-0: 메인 화면 진입 플로우

```mermaid
graph TD
    A[URL 접속] --> B{접속 경로?}

    %% 직접 접속
    B -->|직접 접속| C[메인 화면]

    B -->|결과 공유 링크| D[결과 화면]

    C --> I[테스트 목록 표시]
    I --> J[인기/신규 테스트]
    J --> K[테스트 선택]
    K --> H
    H --> L[테스트 시작]
```

## 3. FEAT-1: AI 심리테스트 플로우

```mermaid
graph TD
    A[테스트 시작] --> B[질문 1 표시]
    B --> C[답변 선택]

    D -->|No| E[다음 질문]
    E --> B

    D -->|Yes| F[답변 제출]

    I --> N[결과 화면]
    L --> N
    M --> O[재시도 안내]
    O --> F

    N --> P[결과 내용 표시]
    P --> Q[공유 버튼]
```

## 8. 모바일 vs PC 화면 차이

### 8.1 공통 요소
- 테스트 진행 플로우 동일
- 결과 화면 레이아웃 동일
- 공유 기능 동일

### 8.2 모바일 전용
- 하단 네비게이션 바
- 스와이프 제스처 (질문 이동)
- 카카오톡 공유 버튼 우선 배치

### 8.3 PC 전용
- 사이드바 (다른 테스트 목록)
- 키보드 네비게이션 (1,2,3,4 키로 답변)
- 링크 복사 버튼 우선 배치

## 9. 광고 배치 포인트

```mermaid
graph TD
    A[메인 화면] --> B[배너 광고 #1<br/>하단]

    C[테스트 중간] --> D[네이티브 광고<br/>질문 3~4개마다]

    E[결과 화면] --> F[배너 광고 #2<br/>결과 아래]
    E --> G[네이티브 광고<br/>관련 테스트 사이]

    style B fill:#ffeb3b
    style D fill:#ffeb3b
    style F fill:#ffeb3b
    style G fill:#ffeb3b
```

### 광고 원칙
- 테스트 시작 전: 광고 최소화 (이탈 방지)
- 테스트 중: 적절한 간격으로 네이티브 광고
- 결과 후: 메인 광고 노출 (만족 상태에서 노출)
- 전체: 과하지 않게, UX 해치지 않게
