# 나의 연애 유형은? - 심리테스트 콘텐츠 설계서

> **테스트명**: 나의 연애 유형은?
> **문항 수**: 20개 (각 2지선다)
> **결과 유형**: 20개
> **측정 차원**: 5축 (적극성, 감정표현, 독립성, 헌신도, 로맨스)
> **타겟**: 20대 MZ세대
> **톤앤매너**: 재치있고 위트있는 MZ 감성, 공감가는 표현

## 1. 심리학적 프레임워크

### 1.1 이론적 배경

본 테스트는 다음의 심리학적 이론을 기반으로 설계되었습니다.

#### 1) 애착 이론 (Attachment Theory)
- **John Bowlby & Mary Ainsworth**의 연구 기반
- 어린 시절 양육자와의 관계가 성인기 연애 패턴에 영향
- 안정형, 불안형, 회피형, 혼란형의 4가지 애착 유형
- 본 테스트에서는 **독립성**과 **헌신도** 차원에 반영

#### 2) 사랑의 삼각형 이론 (Triangular Theory of Love)
- **Robert Sternberg**의 연구 기반
- 친밀감(Intimacy), 열정(Passion), 헌신(Commitment)의 3요소
- 본 테스트에서는 **감정표현**, **로맨스**, **헌신도** 차원에 반영

#### 3) 사랑의 언어 (5 Love Languages)
- **Gary Chapman**의 연구 기반
- 확언, 봉사, 선물, 시간, 스킨십의 5가지 표현 방식
- 본 테스트에서는 **감정표현**과 **로맨스** 차원에 반영

#### 4) 능동-수동 연애 스타일
- 연애에서의 주도권과 에너지 방향
- 본 테스트에서는 **적극성** 차원에 반영

### 1.2 측정 차원 정의 (5축)

| 차원 | 정의 | 낮음 (0-50) | 높음 (51-100) |
|------|------|-------------|---------------|
| **적극성 (Proactivity)** | 연애에서 먼저 다가가고 주도하는 정도 | 수동적, 기다리는 스타일 | 적극적, 먼저 다가가는 스타일 |
| **감정표현 (Expression)** | 감정을 말과 행동으로 표현하는 정도 | 내면에 간직, 표현 절제 | 솔직한 표현, 감정 공유 |
| **독립성 (Independence)** | 연인과 개인 시간/공간의 균형 | 함께하는 시간 중시, 밀착형 | 개인 시간 중시, 자율형 |
| **헌신도 (Commitment)** | 관계에 투자하고 책임지려는 정도 | 가볍고 자유로운 관계 선호 | 진지하고 깊은 관계 선호 |
| **로맨스 (Romance)** | 로맨틱한 분위기와 이벤트 선호도 | 현실적, 실용적 사랑 | 낭만적, 감성적 사랑 |

### 1.3 차원 조합과 유형 분류 원리

5개 차원의 High(H)/Low(L) 조합으로 32가지가 가능하나, 유의미한 20개 유형으로 클러스터링하여 분류합니다.

```
유형 분류 로직:
1. 5개 차원 점수를 50점 기준으로 H/L 분류
2. 핵심 차원 2-3개의 조합으로 1차 분류 (8개 그룹)
3. 보조 차원으로 2차 세분화 (20개 유형)
```

### 4.4 점수 정규화 (0-100 스케일)

```typescript
interface NormalizedScores {
  proactivity: number;    // 0-100
  expression: number;     // 0-100
  independence: number;   // 0-100
  commitment: number;     // 0-100
  romance: number;        // 0-100
}

function normalizeScores(raw: DimensionScores): NormalizedScores {
  return {
    proactivity: Math.round((raw.proactivity / 10) * 100),
    expression: Math.round((raw.expression / 8) * 100),
    independence: Math.round((raw.independence / 8) * 100),
    commitment: Math.round((raw.commitment / 6) * 100),
    romance: Math.round((raw.romance / 8) * 100)
  };
}
```

```typescript
  | 'sweet_talker'         // 12. 말로 하는 사랑꾼
  | 'honest_lover'         // 13. 팩폭 애정러
  | 'mood_creator'         // 14. 로맨틱 무드메이커
  | 'long_distance_pro'    // 15. 장거리 전문가
  | 'daily_companion'      // 16. 일상 동반자
  | 'slow_burner'          // 17. 슬로우 버너
  | 'careful_observer'     // 18. 신중한 관찰자
  | 'practical_lover'      // 19. 현실주의 연인
  | 'emotional_dreamer';   // 20. 감성 몽글러

function determineLoveType(scores: NormalizedScores): LoveType {
  const { proactivity, expression, independence, commitment, romance } = scores;

  // 각 차원의 High(50 이상) / Low(50 미만) 분류
  const isProactive = proactivity >= 50;
  const isExpressive = expression >= 50;
  const isIndependent = independence >= 50;
  const isCommitted = commitment >= 50;
  const isRomantic = romance >= 50;

  // 1차: 적극성 기반 분류
  if (proactivity >= 80) {
    // 매우 적극적
    if (isRomantic && isExpressive) return 'romance_express';  // 03
    if (isExpressive && !isIndependent) return 'straight_shooter';  // 01
    if (isRomantic) return 'mood_creator';  // 14
    return 'straight_shooter';  // 01
  }

  if (proactivity <= 20) {
    // 매우 소극적
    if (!isExpressive && isCommitted) return 'careful_observer';  // 18
    if (isIndependent) return 'slow_burner';  // 17
    return 'slow_burner';  // 17
  }

  // 2차: 감정표현 기반 분류
  if (expression >= 80) {
    if (isRomantic) return 'sweet_talker';  // 12
    if (isCommitted) return 'emotion_translator';  // 05
    return 'sweet_talker';  // 12
  }

  if (expression <= 20) {
    if (isProactive) return 'tsundere_expert';  // 04
    if (!isRomantic) return 'honest_lover';  // 13
    return 'tsundere_expert';  // 04
  }

  // 3차: 독립성 기반 분류
  if (independence >= 80) {
    if (!isCommitted) return 'free_spirit';  // 08
    return 'independent_lover';  // 10
  }

  if (independence <= 20) {
    if (isCommitted) return 'devoted_partner';  // 09
    if (isExpressive) return 'touch_fairy';  // 11
    return 'devoted_partner';  // 09
  }

  // 4차: 헌신도 기반 분류
  if (commitment >= 80) {
    if (isRomantic) return 'devoted_partner';  // 09
    if (!isRomantic) return 'practical_lover';  // 19
    return 'steady_lover';  // 07
  }

  if (commitment <= 20) {
    if (isRomantic) return 'thrill_collector';  // 06
    return 'free_spirit';  // 08
  }

  // 5차: 로맨스 기반 분류
  if (romance >= 80) {
    if (isProactive) return 'romance_express';  // 03
    return 'emotional_dreamer';  // 20
  }

  if (romance <= 20) {
    if (isIndependent) return 'practical_lover';  // 19
    return 'daily_companion';  // 16
  }

  // 6차: 복합 조합
  if (isProactive && !isExpressive) return 'push_pull_master';  // 02
  if (!isProactive && isExpressive && isRomantic) return 'emotional_dreamer';  // 20
  if (isIndependent && !isCommitted) return 'long_distance_pro';  // 15
  if (!isIndependent && isCommitted) return 'steady_lover';  // 07
  if (!isRomantic && isCommitted) return 'daily_companion';  // 16

  // 기본값: 중립적 유형
  return 'steady_lover';  // 07
}
```

### 5.3 전체 분석 함수

```typescript
interface Answer {
  questionId: string;
  choiceId: "A" | "B";
}

interface FullAnalysisResult {
  rawScores: DimensionScores;
  normalizedScores: NormalizedScores;
  primaryType: LoveType;
  typeData: LoveTypeData;
}

function analyzeTestResult(answers: Answer[]): FullAnalysisResult {
  // 1. 원점수 계산
  const rawScores: DimensionScores = {
    proactivity: 0,
    expression: 0,
    independence: 0,
    commitment: 0,
    romance: 0
  };

  answers.forEach(answer => {
    const questionScores = QUESTION_SCORES[answer.questionId];
    if (!questionScores) return;

    const choiceScore = questionScores[answer.choiceId];
    if (!choiceScore) return;

    rawScores.proactivity += choiceScore.proactivity;
    rawScores.expression += choiceScore.expression;
    rawScores.independence += choiceScore.independence;
    rawScores.commitment += choiceScore.commitment;
    rawScores.romance += choiceScore.romance;
  });

  // 2. 정규화
  const normalizedScores = normalizeScores(rawScores);

  // 3. 유형 결정
  const primaryType = determineLoveType(normalizedScores);

  // 4. 유형 데이터 조회
  const typeData = LOVE_TYPE_DATA[primaryType];

  return {
    rawScores,
    normalizedScores,
    primaryType,
    typeData
  };
}
```

1. **심리학적 프레임워크**
   - 애착 이론, 사랑의 삼각형 이론, 사랑의 언어 이론 기반
   - 5개 측정 차원 정의 (적극성, 감정표현, 독립성, 헌신도, 로맨스)

2. **20개 결과 유형 설계**
   - 각 유형별 캐치한 유형명, 한줄 설명, 상세 설명
   - 연애 스타일 특징, 강점, 성장 포인트
   - 궁합 유형 및 SNS 공유용 해시태그

3. **20개 문항 설계**
   - MZ 감성의 실제 연애 상황 기반 문항
   - A/B 이지선다 (둘 다 매력적인 선택지)
   - 측정 차원 및 점수 매핑 완료

4. **점수 체계**
   - 5개 차원별 점수 집계 로직
   - 0-100 정규화 스케일
   - 유형 분류 알고리즘 (TypeScript)
   - 테스트 케이스 포함

### 특징

- 모든 유형이 긍정적 표현 (부정적 낙인 없음)

- 다양한 연애 상황 반영 (썸, 연애 중, 일상 등)
