> **테스트 ID**: color-personality

> **카테고리**: personality

## 1. 심리학적 프레임워크

### 1.1 이론적 배경

본 테스트는 색채 심리학(Color Psychology)을 기반으로, 개인의 성격 특성을 색깔에 매칭하여 직관적이고 감성적으로 표현하는 것을 목표로 합니다.

#### 1) 색채 심리학 (Color Psychology)

- **Johann Wolfgang von Goethe**의 색채론(Theory of Colours, 1810) 기반
- 색깔이 인간의 감정과 성격에 대응한다는 심리학적 전통
- 따뜻한 색(빨강, 주황, 노랑)은 에너지, 열정, 활동성과 연결
- 차가운 색(파랑, 하늘, 보라)은 안정, 사색, 내면과 연결
- 본 테스트에서는 **에너지 방향** 차원에 반영

#### 2) DISC 행동 유형 이론

- **William Moulton Marston**의 연구 기반
- 주도형(D), 사교형(I), 안정형(S), 신중형(C) 4가지 행동 패턴
- 감정 표현의 방식과 대인관계 스타일을 분류
- 본 테스트에서는 **감성 유형** 차원에 반영

#### 3) 외향-내향 성격 차원

- **Carl Jung**의 심리 유형론 기반
- 에너지를 외부 세계에서 얻는지(외향), 내면 세계에서 얻는지(내향)
- 사회적 상호작용에서의 선호와 태도를 측정
- 본 테스트에서는 **사회적 성향** 차원에 반영

### 1.2 측정 차원 정의 (3축)

| 차원 | 코드 | 정의 | A 방향 (0점) | B 방향 (1점) |
|------|------|------|-------------|-------------|
| **에너지 방향 (Energy)** | `E` | 활동적/정적 에너지 스펙트럼 | 따뜻함 (Warm): 활동적, 열정적, 역동적 | 차가움 (Cool): 차분한, 사색적, 고요한 |
| **감성 유형 (Emotion)** | `M` | 감성 표현 방식 | 감성적 (Feeling): 감정 중심, 직관적, 공감적 | 이성적 (Thinking): 논리 중심, 분석적, 객관적 |
| **사회적 성향 (Social)** | `S` | 대인관계 에너지 방향 | 확산형 (Outward): 사교적, 주도적, 에너지 발산 | 집중형 (Inward): 독립적, 관찰자, 에너지 보존 |

### 1.3 차원 조합과 유형 분류 원리

3개 차원의 점수 조합으로 최대 8가지 기본 그룹이 가능하며, 세부 점수 편차에 따라 10개 색깔 유형으로 클러스터링합니다.

```
유형 분류 로직:
1. 10개 문항에서 3개 차원별 점수를 합산 (차원당 3~4문항)
2. 각 차원별 점수를 기준값과 비교
3. 3축 조합 + 특정 차원 우세도를 종합하여 10개 유형 중 하나로 배정
```

## 4. 점수 체계 및 유형 분류

### 4.1 차원별 문항 매핑

| 차원 | 측정 문항 | 문항 수 | 점수 범위 |
|------|----------|---------|----------|
| 에너지 방향 (E) | Q1, Q5, Q8 | 3개 | 0~3 |
| 감성 유형 (M) | Q2, Q4, Q7, Q10 | 4개 | 0~4 |
| 사회적 성향 (S) | Q3, Q6, Q9 | 3개 | 0~3 |

### 4.2 유형 분류 매트릭스

각 차원의 점수를 기준값으로 분류합니다.

- **에너지 방향 (E)**: 0~1 = Warm(따뜻함), 2~3 = Cool(차가움)
- **감성 유형 (M)**: 0~2 = Feeling(감성적), 3~4 = Thinking(이성적)
- **사회적 성향 (S)**: 0~1 = Outward(확산형), 2~3 = Inward(집중형)

| E (에너지) | M (감성) | S (사회) | 결과 유형 |
|-----------|---------|---------|----------|
| Warm (0~1) | Feeling (0~2) | Outward (0~1) | 빨강 (열정 스파크) |
| Warm (0~1) | Feeling (0~2) | Inward (2~3) | 핑크 (사랑의 아이콘) |
| Warm (0~1) | Thinking (3~4) | Outward (0~1) | 주황 (무드 메이커) |
| Warm (0~1) | Thinking (3~4) | Inward (2~3) | 노랑 (아이디어 스파클러) |
| Cool (2~3) | Feeling (0~2) | Outward (0~1) | 초록 (힐링 가디언) |
| Cool (2~3) | Feeling (0~2) | Inward (2~3) | 보라 (미스터리 드리머) |
| Cool (2~3) | Thinking (3~4) | Outward (0~1) | 하늘 (맑은 공기 같은 존재) |
| Cool (2~3) | Thinking (3~4) | Inward (2~3) | 파랑 (깊은 바다 사색가) |

**나머지 2가지 유형 (특수 조합)**:

| 조건 | 결과 유형 |
|------|----------|
| E=0 **AND** M=0 **AND** S=0 (모든 차원 최소) | 하양 (퓨어 소울) |
| E=3 **AND** M=4 **AND** S=3 (모든 차원 최대) | 검정 (카리스마 오라) |

> **참고**: 하양과 검정은 모든 차원에서 극단적으로 한쪽으로 치우친 특수한 경우에 해당합니다. 하양은 완전한 따뜻함+감성+확산 조합(원점)으로 어디에도 물들지 않은 순수함을, 검정은 완전한 차가움+이성+집중 조합(최대점)으로 모든 것을 흡수한 깊이를 상징합니다.

### 4.3 TypeScript 점수 계산 코드

```typescript
// ===== 색깔 성격 테스트 점수 계산 =====

// 차원 타입 정의
type Dimension = 'E' | 'M' | 'S';

// 답변 타입 (A = 0점, B = 1점)
type Answer = 'A' | 'B';

// 문항별 측정 차원 매핑
const questionDimensionMap: Record<number, Dimension> = {
  1: 'E',   // 에너지 방향
  2: 'M',   // 감성 유형
  3: 'S',   // 사회적 성향
  4: 'M',   // 감성 유형
  5: 'E',   // 에너지 방향
  6: 'S',   // 사회적 성향
  7: 'M',   // 감성 유형
  8: 'E',   // 에너지 방향
  9: 'S',   // 사회적 성향
  10: 'M',  // 감성 유형
};

// 결과 유형 정의
type ColorResult =
  | 'red'        // 빨강 - 열정 스파크
  | 'orange'     // 주황 - 무드 메이커
  | 'yellow'     // 노랑 - 아이디어 스파클러
  | 'green'      // 초록 - 힐링 가디언
  | 'skyblue'    // 하늘 - 맑은 공기 같은 존재
  | 'blue'       // 파랑 - 깊은 바다 사색가
  | 'purple'     // 보라 - 미스터리 드리머
  | 'pink'       // 핑크 - 사랑의 아이콘
  | 'white'      // 하양 - 퓨어 소울
  | 'black';     // 검정 - 카리스마 오라

// 차원별 점수 계산
function calculateDimensionScores(
  answers: Record<number, Answer>
): Record<Dimension, number> {
  const scores: Record<Dimension, number> = { E: 0, M: 0, S: 0 };

  for (const [questionNum, answer] of Object.entries(answers)) {
    const qNum = Number(questionNum);
    const dimension = questionDimensionMap[qNum];
    if (dimension) {
      scores[dimension] += answer === 'B' ? 1 : 0;
    }
  }

  return scores;
}

// 결과 유형 판정
function determineColorType(
  scores: Record<Dimension, number>
): ColorResult {
  const { E, M, S } = scores;

  // 특수 유형: 모든 차원 최소 (완전 Warm + Feeling + Outward)
  if (E === 0 && M === 0 && S === 0) {
    return 'white';
  }

  // 특수 유형: 모든 차원 최대 (완전 Cool + Thinking + Inward)
  if (E === 3 && M === 4 && S === 3) {
    return 'black';
  }

  // 기본 8가지 조합
  const isWarm = E <= 1;    // Warm: 0~1, Cool: 2~3
  const isFeeling = M <= 2; // Feeling: 0~2, Thinking: 3~4
  const isOutward = S <= 1; // Outward: 0~1, Inward: 2~3

  if (isWarm && isFeeling && isOutward) return 'red';
  if (isWarm && isFeeling && !isOutward) return 'pink';
  if (isWarm && !isFeeling && isOutward) return 'orange';
  if (isWarm && !isFeeling && !isOutward) return 'yellow';
  if (!isWarm && isFeeling && isOutward) return 'green';
  if (!isWarm && isFeeling && !isOutward) return 'purple';
  if (!isWarm && !isFeeling && isOutward) return 'skyblue';
  if (!isWarm && !isFeeling && !isOutward) return 'blue';

  // 폴백 (이론적으로 도달하지 않음)
  return 'white';
}

// === 사용 예시 ===
const userAnswers: Record<number, Answer> = {
  1: 'A',   // E=0
  2: 'A',   // M=0
  3: 'A',   // S=0
  4: 'B',   // M=1
  5: 'A',   // E=0
  6: 'B',   // S=1
  7: 'A',   // M=0
  8: 'A',   // E=0
  9: 'A',   // S=0
  10: 'A',  // M=0
};

const scores = calculateDimensionScores(userAnswers);
// scores = { E: 0, M: 1, S: 1 }

const result = determineColorType(scores);
// result = 'red' (Warm + Feeling + Outward)

console.log(`차원별 점수: E=${scores.E}, M=${scores.M}, S=${scores.S}`);
console.log(`결과 유형: ${result}`);
```

## 5. 문항 설계 근거

### 5.1 심리측정학적 고려사항

1. **내적 일관성**: 각 차원별 3~4문항이 동일 구성개념을 안정적으로 측정
2. **구성 타당도**: 에너지 방향, 감성 유형, 사회적 성향의 3축이 색채 심리학 이론에 부합
3. **안면 타당도**: 일상 상황 기반의 직관적 문항으로 응답자가 자연스럽게 반응
4. **사회적 바람직성 최소화**: A/B 선택지 모두 긍정적으로 구성하여 "정답" 없음

### 5.2 문항 분포

| 측정 차원 | 문항 번호 | 문항 수 | 상황 |
|----------|----------|---------|------|
| 에너지 방향 (E) | Q1, Q5, Q8 | 3개 | 일상, 스트레스, 의사결정 |
| 감성 유형 (M) | Q2, Q4, Q7, Q10 | 4개 | 공감, 여행, 영화, SNS |
| 사회적 성향 (S) | Q3, Q6, Q9 | 3개 | 새로운 모임, 칭찬, 데이트 |

### 5.3 A/B 선택지 설계 원칙

- 두 선택지 모두 **긍정적이고 매력적인** 표현으로 구성
- MZ세대가 **일상에서 공감**할 수 있는 구체적 상황
- 어떤 선택을 해도 **자기 자신이 좋아 보이는** 느낌
- 감성적이고 예쁜 문장으로 **테스트 자체가 즐거운 경험**
