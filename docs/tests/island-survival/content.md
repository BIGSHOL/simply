> **테스트 ID**: island-survival

## 1. 심리학적 프레임워크

### 1.1 컨셉

무인도에 갑자기 표류했을 때, 당신이 맡게 될 생존 역할은 무엇인가?
10가지 극한 상황 속 선택을 통해 당신의 행동 성향, 사회성, 위기 대처 방식을 파악하고
8가지 생존 유형 중 하나를 부여합니다.

### 1.2 측정 차원 (3축)

| 차원 | 코드 | 정의 | A 방향 (0점) | B 방향 (1점) |
|------|------|------|-------------|-------------|
| **행동 성향 (Action)** | `ACT` | 위기 상황에서의 행동 패턴 | 신중/계획형: 관찰하고 분석한 뒤 움직인다 | 실행/돌격형: 일단 몸부터 움직인다 |
| **사회성 (Social)** | `SOC` | 생존 시 대인관계 방식 | 독립/자율형: 혼자서도 잘 해낸다 | 협력/사교형: 함께할 때 시너지가 난다 |
| **위기 대처 (Crisis)** | `CRI` | 위기 상황의 대응 스타일 | 이성/분석형: 논리와 전략으로 해결한다 | 직감/창의형: 번뜩이는 아이디어로 돌파한다 |

### 1.3 차원 조합과 유형 분류 원리

3개 차원의 High(H)/Low(L) 조합으로 2^3 = 8가지 유형이 생성됩니다.

```
유형 분류 로직:
1. 10개 문항 응답 → 3개 차원별 점수 합산
2. 차원별 중앙값 기준으로 H/L 분류
   - ACT: 0~1 = L (신중), 2~3 = H (실행)
   - SOC: 0~1 = L (독립), 2~4 = H (협력)
   - CRI: 0~1 = L (이성), 2~3 = H (직감)
3. 3축 조합으로 8개 유형 결정
```

| ACT | SOC | CRI | 유형 코드 | 유형명 |
|-----|-----|-----|----------|--------|
| L | L | L | LLL | 섬의 전략가 |
| L | L | H | LLH | 표류한 맥가이버 |
| L | H | L | LHL | 섬의 대통령 |
| L | H | H | LHH | 난파선의 힐러 |
| H | L | L | HLL | 고독한 사냥꾼 |
| H | L | H | HLH | 야생의 탐험가 |
| H | H | L | HHL | 해변의 외교관 |
| H | H | H | HHH | 낙원의 요리사 |

### 4.3 TypeScript 점수 계산 코드

```typescript
// === 무인도 생존 유형 점수 계산 ===

// 차원 정의
type Dimension = 'ACT' | 'SOC' | 'CRI';
type Level = 'H' | 'L';

// 결과 유형 정의
interface SurvivalType {
  code: string;        // e.g., "LLL"
  resultType: string;  // e.g., "island-strategist"
  title: string;       // e.g., "섬의 전략가"
  subtitle: string;    // 한줄 설명
}

// 문항별 차원 매핑
const questionDimensionMap: Record<number, Dimension> = {
  1: 'ACT',
  2: 'SOC',
  3: 'CRI',
  4: 'ACT',
  5: 'SOC',
  6: 'CRI',
  7: 'ACT',
  8: 'SOC',
  9: 'CRI',
  10: 'SOC',
};

// 점수 계산: A = 0, B = 1
// answers 배열은 [Q1응답, Q2응답, ..., Q10응답] (각 'A' 또는 'B')
function calculateDimensionScores(answers: ('A' | 'B')[]): Record<Dimension, number> {
  const scores: Record<Dimension, number> = { ACT: 0, SOC: 0, CRI: 0 };

  answers.forEach((answer, index) => {
    const questionNumber = index + 1;
    const dimension = questionDimensionMap[questionNumber];
    if (answer === 'B') {
      scores[dimension] += 1;
    }
  });

  return scores;
}

// H/L 판정
function getDimensionLevel(scores: Record<Dimension, number>): Record<Dimension, Level> {
  return {
    ACT: scores.ACT >= 2 ? 'H' : 'L',  // 3문항 중 2개 이상이면 H
    SOC: scores.SOC >= 2 ? 'H' : 'L',   // 4문항 중 2개 이상이면 H
    CRI: scores.CRI >= 2 ? 'H' : 'L',   // 3문항 중 2개 이상이면 H
  };
}

// 유형 코드 생성
function getTypeCode(levels: Record<Dimension, Level>): string {
  return `${levels.ACT}${levels.SOC}${levels.CRI}`;
}

// 8개 유형 매핑
const survivalTypes: Record<string, SurvivalType> = {
  'LLL': {
    code: 'LLL',
    resultType: 'island-strategist',
    title: '섬의 전략가',
    subtitle: '생존 확률? 이미 엑셀로 계산 끝났는데요',
  },

    title: '섬의 대통령',

  },

    resultType: 'shipwreck-healer',
    title: '난파선의 힐러',

  },
  'HLL': {
    code: 'HLL',
    resultType: 'lone-hunter',
    title: '고독한 사냥꾼',
    subtitle: '말보다 행동, 혼자서 식량 문제 해결 완료',
  },
  'HLH': {
    code: 'HLH',
    resultType: 'wild-explorer',
    title: '야생의 탐험가',
    subtitle: '무인도가 놀이터, 탐험이 곧 생존인 모험가',
  },
  'HHL': {
    code: 'HHL',
    resultType: 'beach-diplomat',
    title: '해변의 외교관',
    subtitle: '표류자들 사이 갈등? 내가 다 해결해줄게',
  },

```

야생의 탐험가(HLH) ←→ 섬의 전략가(LLL), 표류한 맥가이버(LLH)
해변의 외교관(HHL) ←→ 섬의 대통령(LHL), 난파선의 힐러(LHH)

**궁합 설계 원리**: 보완 관계 (부족한 차원을 채워주는 유형끼리 궁합이 좋음)

- 독립형(L-SOC) ↔ 협력형(H-SOC): 개인과 팀의 균형
