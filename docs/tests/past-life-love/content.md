## 1. 심리학적 프레임워크

### 1.1 컨셉

전생의 시대와 배경 속에서 나의 연애 캐릭터를 발견하는 테스트입니다. 시대극, 판타지 소설, 역사 로맨스에서 영감을 받아 다양한 시대와 문화권의 로맨틱 캐릭터 유형으로 결과를 제공합니다. 모든 결과는 긍정적이고 매력적으로 설계되어 "공유하고 싶은" 결과를 만듭니다.

### 1.2 이론적 배경

#### 1) 사랑의 삼각형 이론 (Triangular Theory of Love)
- **Robert Sternberg**의 연구 기반
- 친밀감(Intimacy), 열정(Passion), 헌신(Commitment)의 3요소
- 본 테스트에서는 **로맨스 강도** 차원에 반영

#### 2) 사랑의 언어 (5 Love Languages)
- **Gary Chapman**의 연구 기반
- 확언, 봉사, 선물, 시간, 스킨십의 5가지 표현 방식
- 본 테스트에서는 **사랑 표현 방식** 차원에 반영

#### 3) 능동-수동 연애 스타일
- 연애에서의 주도권과 에너지 방향
- 본 테스트에서는 **관계 주도성** 차원에 반영

### 1.3 측정 차원 정의 (3축)

| 차원 | 코드 | 정의 | A (0점) | B (1점) |
|------|------|------|---------|---------|
| **사랑 표현 방식 (Expression)** | `E` | 사랑을 표현하는 주된 방식 | 행동형: 말보다 행동으로 보여주는 스타일 | 감정형: 말과 감정으로 직접 전하는 스타일 |
| **관계 주도성 (Initiative)** | `I` | 관계에서 주도하는 정도 | 수용형: 상대에 맞추고 지지하는 스타일 | 주도형: 적극적으로 이끌고 리드하는 스타일 |
| **로맨스 강도 (Intensity)** | `R` | 사랑의 깊이와 열정의 강도 | 온건형: 잔잔하고 깊은 사랑 | 열정형: 불꽃같이 뜨거운 사랑 |

### 1.4 차원 조합과 유형 분류 원리

3개 차원의 High(H)/Low(L) 조합으로 8가지(2^3) 유형이 결정됩니다.

```
분류 로직:
1. 각 차원별 배정된 문항의 B 선택 수를 합산
2. 차원별 점수가 기준(중앙값) 이상이면 H, 미만이면 L
3. 3개 차원의 H/L 조합으로 8개 유형 중 하나로 분류

차원별 문항 배정:
- E (사랑 표현 방식): Q1, Q4, Q7, Q10 → 4문항 (0~4점), 기준 2점
- I (관계 주도성):   Q2, Q5, Q8     → 3문항 (0~3점), 기준 2점
- R (로맨스 강도):   Q3, Q6, Q9     → 3문항 (0~3점), 기준 2점
```

| E | I | R | 유형 코드 | 결과 유형 |
|---|---|---|-----------|-----------|
| L | L | L | EaIaRa | 조선시대 내조의 여왕/왕 |
| L | L | H | EaIaRb | 로마의 검투사 연인 |
| L | H | L | EaIbRa | 빅토리아 시대 귀족 |
| L | H | H | EaIbRb | 해적선의 캡틴 러버 |
| H | L | L | EbIaRa | 헤이안 시대 궁정 시인 |
| H | L | H | EbIaRb | 이집트 파라오의 연인 |
| H | H | L | EbIbRa | 르네상스 예술가의 뮤즈 |
| H | H | H | EbIbRb | 그리스 신화 운명의 연인 |

// --- 점수 계산 함수 ---

/**
 * 사용자 응답(A/B)을 차원별 점수로 변환
 * @param answers - 10개 문항에 대한 A/B 응답 배열
 * @returns 차원별 합산 점수
 */
function calculateDimensionScores(answers: Choice[]): DimensionScores {
  const scores: DimensionScores = { E: 0, I: 0, R: 0 };

  answers.forEach((choice, index) => {
    const question = questions[index];
    if (choice === 'B') {
      scores[question.dimension] += 1;
    }
  });

  return scores;
}

/**
 * 차원별 점수를 H/L 레벨로 변환
 * - E: 4문항 → 기준 2점 (2 이상이면 H)
 * - I: 3문항 → 기준 2점 (2 이상이면 H)
 * - R: 3문항 → 기준 2점 (2 이상이면 H)
 */
function getDimensionLevels(scores: DimensionScores): DimensionLevels {
  return {
    E: scores.E >= 2 ? 'H' : 'L',
    I: scores.I >= 2 ? 'H' : 'L',
    R: scores.R >= 2 ? 'H' : 'L',
  };
}

/**
 * 차원 레벨 조합으로 결과 유형 ID 결정
 *
 * | E | I | R | 유형 ID | 유형명 |
 * |---|---|---|---------|--------|
 * | L | L | L |    1    | 조선시대 내조의 여왕/왕 |
 * | L | L | H |    2    | 로마의 검투사 연인 |
 * | L | H | L |    3    | 빅토리아 시대 귀족 |
 * | L | H | H |    4    | 해적선의 캡틴 러버 |
 * | H | L | L |    5    | 헤이안 시대 궁정 시인 |
 * | H | L | H |    6    | 이집트 파라오의 연인 |
 * | H | H | L |    7    | 르네상스 예술가의 뮤즈 |
 * | H | H | H |    8    | 그리스 신화 운명의 연인 |
 */
function getResultTypeId(levels: DimensionLevels): ResultTypeId {
  const key = `${levels.E}${levels.I}${levels.R}`;

  const mapping: Record<string, ResultTypeId> = {
    LLL: 1,
    LLH: 2,
    LHL: 3,
    LHH: 4,
    HLL: 5,
    HLH: 6,
    HHL: 7,
    HHH: 8,
  };

  return mapping[key];
}

/**
 * 최종 결과 산출: 응답 배열 → 결과 유형 반환
 */
function getResult(answers: Choice[]): ResultType {
  const scores = calculateDimensionScores(answers);
  const levels = getDimensionLevels(scores);
  const typeId = getResultTypeId(levels);

  return resultTypes.find((rt) => rt.id === typeId)!;
}
