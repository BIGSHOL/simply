# 나의 회의실 생존 유형은? - 심리테스트 콘텐츠 설계서

> **테스트명**: 나의 회의실 생존 유형은?
> **문항 수**: 10개 (각 2지선다)
> **결과 유형**: 8개
> **측정 차원**: 3축 (의견 적극성, 경청 스타일, 시간 민감도)
> **타겟**: 20대 MZ세대 직장인
> **톤앤매너**: 직장인 극공감 + 웃긴 밈 감성

---

## 1. 심리학적 프레임워크

### 1.1 이론적 배경

본 테스트는 다음의 조직심리학 및 커뮤니케이션 이론을 기반으로 설계되었습니다.

#### 1) Belbin의 팀 역할 이론 (Team Role Theory)
- **Meredith Belbin**의 연구 기반 (1981)
- 9가지 팀 내 역할: 실행가, 조정자, 형성가, 자원탐색가, 평가자, 전문가, 협력자, 완성가, 창조자
- 회의에서의 발언 패턴과 기여 방식을 분류
- 본 테스트에서는 **의견 적극성** 차원에 반영

#### 2) 적극적 경청 이론 (Active Listening)
- **Carl Rogers & Richard Farson**의 연구 기반
- 경청의 수준: 수동적 청취 vs 적극적 참여
- 피드백 방식: 공감형 vs 분석형
- 본 테스트에서는 **경청 스타일** 차원에 반영

#### 3) 시간 관리 성향 이론 (Time Orientation)
- **Edward T. Hall**의 다문화 시간 개념
- 단일시간형 (Monochronic): 시간 엄수, 계획적
- 다중시간형 (Polychronic): 유연성, 관계 중심
- 본 테스트에서는 **시간 민감도** 차원에 반영

#### 4) 의사소통 스타일 (Communication Styles)
- 표현형 vs 내향형
- 과업 지향 vs 관계 지향
- 본 테스트의 전체 축에 반영

### 1.2 측정 차원 정의 (3축)

| 차원 코드 | 차원명 | 정의 | A방향 (0점) | B방향 (1점) |
|-----------|--------|------|-------------|-------------|
| **ACT** | 의견 적극성 (Activeness) | 회의에서 의견을 제시하고 토론에 참여하는 정도 | **수동형**: 경청 위주, 필요할 때만 발언 | **적극형**: 활발한 발언, 먼저 의견 제시 |
| **LSN** | 경청 스타일 (Listening) | 타인 의견에 대한 반응 및 피드백 방식 | **공감형**: 수용적, 긍정 피드백 위주 | **분석형**: 비판적 사고, 논리적 반박 |
| **TIM** | 시간 민감도 (Time Sensitivity) | 회의 시간 관리 및 효율성에 대한 민감도 | **유연형**: 과정 중시, 관계 지향 | **엄수형**: 시간 엄수, 결과 지향 |

### 1.3 차원 조합과 유형 분류 원리

3개 차원의 High(1)/Low(0) 조합으로 8가지(2³) 회의실 생존 유형을 분류합니다.

```
유형 분류 로직:
1. 10개 문항 응답 → 각 차원별 점수 합산 (ACT, LSN, TIM)
2. 각 차원 중앙값(각 차원 문항 수 / 2) 기준으로 H/L 분류
3. 3비트 조합 → 8개 유형 매핑

예시:
- ACT(적극형) + LSN(공감형) + TIM(엄수형) → "엔딩요정"
- ACT(수동형) + LSN(분석형) + TIM(유연형) → "조용한 관찰자"
```

**차원별 문항 배분**:
- ACT (의견 적극성): 4문항 (Q1, Q3, Q7, Q9)
- LSN (경청 스타일): 3문항 (Q2, Q5, Q8)
- TIM (시간 민감도): 3문항 (Q4, Q6, Q10)

## 2. 8개 결과 유형 설계

### 유형 1: 조용한 관찰자 (Silent Observer)

| 항목 | 내용 |
|------|------|
| **유형 코드** | `ACT:L / LSN:L / TIM:L` |
| **유형명** | 조용한 관찰자 |
| **한줄 설명** | 조용히 있다가 마지막에 "저도 그렇게 생각합니다" |
| **핵심 키워드** | #경청마스터 #필요할때만발언 #회의관전러 |

**회의실에서의 모습**
당신은 회의실에서 가장 조용한 존재감을 자랑해요. 다른 사람들이 열띤 토론을 할 때 당신은 카메라 끄고 듣기만 해요. "OOO님 의견 어떠세요?" 하고 호명되면 "아 네, 저는 좋을 것 같습니다"라고 대답하는 타입. 회의록에는 당신 이름이 '참석자' 목록에만 있어요. 하지만 당신은 나름 다 듣고 있답니다!

**커뮤니케이션 성향 분석**
- 의견 표현보다는 경청을 선호하는 수동적 스타일
- 타인 의견에 공감은 하지만 피드백은 최소화
- 회의 시간이 길어져도 크게 신경 쓰지 않음
- 갈등 상황을 피하고 조화를 중시

**회의에서의 강점**
- 경청 능력이 뛰어나 전체 흐름을 파악함
- 중립적 위치에서 객관적 판단 가능
- 불필요한 갈등을 만들지 않음
- 조용한 지지자 역할로 팀 안정성 기여

**회의에서의 약점**
- 중요한 의견이 있어도 묻히기 쉬움
- 참여도가 낮아 보일 수 있음
- 의사결정 과정에 충분히 기여하지 못할 수 있음

**잘 맞는 회의 파트너 유형**
- **급발진 토론왕**: 당신이 안 해도 알아서 다 말해줘요
- **아이디어 뱅크**: 적극적인 사람과 함께하면 균형이 맞아요

**직장생활 조언**
작은 의견이라도 먼저 꺼내보는 연습을 해보세요. "제 생각엔..." 한 마디가 당신의 존재감을 크게 만들어요. 회의 전에 미리 의견을 정리해두면 발언하기 훨씬 쉬워져요. 조용하지만 예리한 당신의 한 마디가 회의의 방향을 바꿀 수 있답니다!

### 유형 2: 시간 지킴이 (Time Guardian)

| 항목 | 내용 |
|------|------|
| **유형 코드** | `ACT:L / LSN:L / TIM:H` |
| **유형명** | 시간 지킴이 |
| **한줄 설명** | 시계 보면서 "30분 남았는데요..." 라고 쿡쿡 찌르는 스타일 |
| **핵심 키워드** | #시간엄수 #효율성중시 #야근싫어 |

**회의실에서의 모습**
당신은 회의 시작 1분 전부터 줌 대기실에 서 있는 사람이에요. 회의가 길어지면 노트북 시계를 째려보고, "저희 30분 남았는데 다음 안건 넘어가실까요?"라고 슬쩍 압박하는 타입. 다른 사람들이 잡담할 때 당신은 속으로 '저게 지금 안건이야?' 하고 생각해요. 30분 회의가 31분 가는 걸 못 참는 시간 엄수의 화신!

**커뮤니케이션 성향 분석**
- 발언은 적지만 시간 관리에는 민감
- 불필요한 대화보다 핵심만 빠르게 처리
- 효율성을 최우선 가치로 생각
- 결과 중심적 사고방식

**회의에서의 강점**
- 회의가 산으로 가는 걸 막아주는 타임키퍼
- 시간 내 결론 도출을 독려
- 불필요한 논쟁을 정리하는 능력
- 일정 관리에 철저해 팀 효율성 향상

**회의에서의 약점**
- 충분한 논의 전에 서두르는 것처럼 보일 수 있음
- 관계보다 과업을 우선시해 차갑게 느껴질 수 있음
- 창의적 아이디어를 위한 여유 시간 부족

**잘 맞는 회의 파트너 유형**
- **엔딩요정**: 함께하면 칼퇴근 보장!
- **회의록 장인**: 효율적인 기록으로 시간 절약 가능

**직장생활 조언**
시간 엄수는 훌륭한 덕목이지만, 가끔은 여유롭게 아이디어를 나누는 시간도 필요해요. 브레인스토밍 같은 회의에서는 시계를 잠시 내려놓고 창의성을 발휘해보세요. 당신의 효율성에 따뜻함을 더하면 완벽한 조합이에요!

### 유형 3: 돌직구 리뷰어 (Straight Shooter)

| 항목 | 내용 |
|------|------|
| **유형 코드** | `ACT:L / LSN:H / TIM:L` |
| **유형명** | 돌직구 리뷰어 |
| **한줄 설명** | 조용하다가 갑자기 "근데 그거 문제 있지 않아요?" |
| **핵심 키워드** | #논리파괴자 #예리한지적 #팩트폭격기 |

**회의실에서의 모습**
평소엔 조용히 듣고만 있다가, 뭔가 이상하다 싶으면 "잠깐만요, 그 논리는 모순 아닌가요?"라고 폭탄을 던지는 타입. 다들 좋다고 할 때 혼자 "그런데요..."로 시작하는 발언을 해서 회의를 1시간 연장시키는 주인공. 당신은 팩트와 논리의 수호자, 회의실 속 현실 체크 담당입니다.

**커뮤니케이션 성향 분석**
- 경청하다가 논리적 오류 발견 시 적극 지적
- 비판적 사고가 강하고 분석력이 뛰어남
- 시간보다 정확성과 완성도를 중시
- 감정보다 사실과 데이터 기반 의사소통

**회의에서의 강점**
- 문제점을 조기에 발견하는 리스크 관리자
- 논리적 허점을 찾아내는 예리한 분석력
- 잘못된 결정을 막아주는 안전장치 역할
- 완성도 높은 결과물로 이어지게 함

**회의에서의 약점**
- 분위기를 깨는 사람으로 보일 수 있음
- 지나친 비판으로 팀원들의 의욕 저하 가능
- 완벽주의로 인한 의사결정 지연

**잘 맞는 회의 파트너 유형**
- **아이디어 뱅크**: 창의성과 논리성의 조합
- **회의록 장인**: 당신의 지적사항을 정확히 기록해줘요

**직장생활 조언**
예리한 지적은 훌륭하지만, 전달 방식이 중요해요. "이건 문제가 있어요" 대신 "이 부분을 이렇게 보완하면 어떨까요?"처럼 건설적인 피드백을 주는 연습을 해보세요. 당신의 통찰력에 따뜻한 포장을 더하면 팀의 든든한 조언자가 될 수 있어요!

### 유형 4: 무적의 팔로워 (Ultimate Follower)

| 항목 | 내용 |
|------|------|
| **유형 코드** | `ACT:L / LSN:H / TIM:H` |
| **유형명** | 무적의 팔로워 |
| **한줄 설명** | "좋은 지적입니다만, 시간이 없으니 일단 진행하죠" |
| **핵심 키워드** | #현실주의자 #실용적 #빠른결정 |

**회의실에서의 모습**
당신은 회의에서 리더는 아니지만, 가장 쓸모 있는 사람이에요. 누군가 문제를 제기하면 "맞는 말씀이긴 한데, 일단 데드라인이 내일이니까 이렇게 가는 게 어떨까요?"라고 현실적인 대안을 제시해요. 이상보다 현실, 완벽보다 완성을 추구하는 당신은 회의를 칼퇴로 이끄는 효율의 신!

**커뮤니케이션 성향 분석**
- 문제 인식은 하지만 실용적 해결 우선
- 시간 내 결론 도출을 최우선으로
- 분석적이지만 과도한 논쟁은 회피
- 빠른 의사결정과 실행력 중시

**회의에서의 강점**
- 현실적이고 실행 가능한 대안 제시
- 논쟁을 정리하고 합의점 도출 능력
- 시간 내 결론에 도달하게 함
- 팀의 실행력을 높이는 실용주의자

**회의에서의 약점**
- 너무 타협적이라 근본적 문제 해결 놓칠 수 있음
- 장기적 관점보다 단기 효율 우선
- 혁신적 아이디어가 묻힐 수 있음

**잘 맞는 회의 파트너 유형**
- **엔딩요정**: 최강의 칼퇴 콤비
- **시간 지킴이**: 효율성에서 통하는 사이

**직장생활 조언**
현실적 판단력은 큰 강점이지만, 가끔은 시간을 들여 근본적인 문제를 해결하는 것도 중요해요. 빠른 결정이 항상 최선은 아니니까요. 효율성과 완성도 사이의 균형을 찾으면 더욱 성장할 수 있어요!

### 유형 5: 아이디어 뱅크 (Idea Bank)

| 항목 | 내용 |
|------|------|
| **유형 코드** | `ACT:H / LSN:L / TIM:L` |
| **유형명** | 아이디어 뱅크 |
| **한줄 설명** | "이거 하면 어때요? 저거 하면 어때요?" 아이디어 폭포수 |
| **핵심 키워드** | #창의력폭발 #브레인스토밍왕 #아이디어발전소 |

**회의실에서의 모습**
당신은 회의가 시작되면 아이디어가 샘솟는 크리에이터! "이거 어때요?", "이런 것도 해볼까요?", "아 그럼 이건요?" 하면서 10분에 아이디어 다섯 개는 기본으로 쏟아내요. 다른 사람이 말하는 걸 듣다가도 "아! 그럼 이렇게 하면 되겠다!"하며 새로운 생각을 추가하는 타입. 회의록 담당자가 당신 말 받아적느라 손목 아파요.

**커뮤니케이션 성향 분석**
- 활발한 발언과 창의적 아이디어 제시
- 다른 의견에 긍정적으로 반응하며 확장
- 시간 제약보다 아이디어 발전에 집중
- 브레인스토밍에서 진가를 발휘

**회의에서의 강점**
- 창의적 아이디어로 새로운 방향 제시
- 팀의 창의성과 혁신을 이끎
- 긍정적 에너지로 회의 분위기 활성화
- 다양한 관점에서 문제 접근

**회의에서의 약점**
- 너무 많은 아이디어로 초점 흐려질 수 있음
- 실행 가능성보다 참신함 우선
- 회의 시간이 길어지는 원인 제공
- 결론 도출이 어려워질 수 있음

**잘 맞는 회의 파트너 유형**
- **돌직구 리뷰어**: 당신의 아이디어를 논리적으로 검증해줘요
- **회의록 장인**: 당신의 아이디어를 빠짐없이 정리해줘요

**직장생활 조언**

## 4. 점수 산출 로직

### 4.1 차원별 점수 계산

각 응답의 배점을 차원별로 합산합니다.

| 차원 | 측정 문항 | 최대 점수 |
|------|----------|----------|
| ACT (의견 적극성) | Q1, Q3, Q7, Q9 | 4점 |
| LSN (경청 스타일) | Q2, Q5, Q8 | 3점 |
| TIM (시간 민감도) | Q4, Q6, Q10 | 3점 |

**계산 예시**:
```
사용자 응답:
Q1=B(1), Q2=A(0), Q3=B(1), Q4=B(1), Q5=A(0),
Q6=A(0), Q7=B(1), Q8=B(1), Q9=A(0), Q10=B(1)

차원별 점수:
- ACT = Q1(1) + Q3(1) + Q7(1) + Q9(0) = 3점
- LSN = Q2(0) + Q5(0) + Q8(1) = 1점
- TIM = Q4(1) + Q6(0) + Q10(1) = 2점
```

### 4.2 High/Low 분류 기준

각 차원의 중앙값을 기준으로 High(H)/Low(L)를 분류합니다.

| 차원 | 중앙값 | Low (L) | High (H) |
|------|--------|---------|----------|
| ACT | 2.0 | 0-2점 | 3-4점 |
| LSN | 1.5 | 0-1점 | 2-3점 |
| TIM | 1.5 | 0-1점 | 2-3점 |

**분류 예시** (위의 계산 예시 계속):
```
ACT = 3점 → H (3 > 2.0)
LSN = 1점 → L (1 ≤ 1.5)
TIM = 2점 → H (2 > 1.5)

→ 유형: ACT:H / LSN:L / TIM:H → "엔딩요정"
```

### 4.3 유형 매핑 테이블

| ACT | LSN | TIM | 유형 코드 | 유형명 |
|-----|-----|-----|-----------|--------|
| L | L | L | 000 | 조용한 관찰자 |
| L | L | H | 001 | 시간 지킴이 |
| L | H | L | 010 | 돌직구 리뷰어 |
| L | H | H | 011 | 무적의 팔로워 |
| H | L | L | 100 | 아이디어 뱅크 |
| H | L | H | 101 | 엔딩요정 |
| H | H | L | 110 | 급발진 토론왕 |
| H | H | H | 111 | 회의록 장인 |

### 4.4 알고리즘 구현 예시 (Python)

```python
def calculate_meeting_type(answers: dict) -> str:
    """
    회의실 생존 유형 계산

    Args:
        answers: {question_id: choice} 형태
                예: {'Q1': 'B', 'Q2': 'A', ..., 'Q10': 'B'}

    Returns:
        유형명 (예: "엔딩요정")
    """

    # 1. 문항별 차원 및 배점 정의
    scoring = {
        'Q1': {'dimension': 'ACT', 'A': 0, 'B': 1},
        'Q2': {'dimension': 'LSN', 'A': 0, 'B': 1},
        'Q3': {'dimension': 'ACT', 'A': 0, 'B': 1},
        'Q4': {'dimension': 'TIM', 'A': 0, 'B': 1},
        'Q5': {'dimension': 'LSN', 'A': 0, 'B': 1},
        'Q6': {'dimension': 'TIM', 'A': 0, 'B': 1},
        'Q7': {'dimension': 'ACT', 'A': 0, 'B': 1},
        'Q8': {'dimension': 'LSN', 'A': 0, 'B': 1},
        'Q9': {'dimension': 'ACT', 'A': 0, 'B': 1},
        'Q10': {'dimension': 'TIM', 'A': 0, 'B': 1},
    }

    # 2. 차원별 점수 합산
    dimension_scores = {'ACT': 0, 'LSN': 0, 'TIM': 0}

    for q_id, choice in answers.items():
        dim = scoring[q_id]['dimension']
        score = scoring[q_id][choice]
        dimension_scores[dim] += score

    # 3. High/Low 분류
    # ACT: 4문항 → 중앙값 2.0
    # LSN: 3문항 → 중앙값 1.5
    # TIM: 3문항 → 중앙값 1.5

    act_level = 'H' if dimension_scores['ACT'] > 2.0 else 'L'
    lsn_level = 'H' if dimension_scores['LSN'] > 1.5 else 'L'
    tim_level = 'H' if dimension_scores['TIM'] > 1.5 else 'L'

    # 4. 유형 매핑
    type_mapping = {
        ('L', 'L', 'L'): '조용한 관찰자',
        ('L', 'L', 'H'): '시간 지킴이',
        ('L', 'H', 'L'): '돌직구 리뷰어',
```
