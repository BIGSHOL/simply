## 1. 심리학적 프레임워크

### 1.1 이론적 배경

본 테스트는 다음의 심리학적 이론을 기반으로 설계되었습니다.

#### 1) 애착 이론 (Attachment Theory)
- **John Bowlby & Mary Ainsworth**의 연구 기반
- 이별 후 회복 과정은 애착 유형에 따라 다르게 나타남
- 안정형은 건강한 감정 처리, 불안형은 집착, 회피형은 감정 억제 경향
- 본 테스트에서는 **감정처리** 차원에 반영

#### 2) 스트레스 대처 이론 (Coping Theory)
- **Lazarus & Folkman**의 연구 기반
- 문제 중심 대처 vs 감정 중심 대처
- 적극적 대처 vs 회피적 대처
- 본 테스트에서는 **자기돌봄** 차원에 반영

#### 3) 사회적 지지 이론 (Social Support Theory)
- **Cohen & Wills**의 연구 기반
- 정서적 지지, 도구적 지지, 정보적 지지
- 이별 후 회복에 사회적 연결망이 미치는 영향
- 본 테스트에서는 **사회적지지** 차원에 반영

#### 4) 슬픔의 5단계 (Five Stages of Grief)
- **Elisabeth Kübler-Ross**의 연구 기반
- 부정, 분노, 협상, 우울, 수용의 단계
- 개인마다 각 단계를 거치는 방식과 속도가 다름
- 본 테스트에서는 **감정처리** 차원에 반영

#### 5) 긍정심리학 (Positive Psychology)
- **Martin Seligman**의 연구 기반
- 성장적 마인드셋, 회복탄력성
- 역경을 성장의 기회로 전환하는 능력
- 본 테스트에서는 **자기돌봄** 차원에 반영

### 1.2 측정 차원 정의 (3축)

| 차원 코드 | 차원명 | 정의 | A방향 (0점) | B방향 (1점) |
|----------|--------|------|-------------|-------------|
| **E** | **감정처리 (Emotion Processing)** | 이별로 인한 감정을 어떻게 다루는가 | **내면화 (Internalizing)**<br>감정을 혼자 곱씹고 내면에서 처리하는 스타일 | **외현화 (Externalizing)**<br>감정을 표출하고 타인과 나누며 처리하는 스타일 |
| **S** | **사회적지지 (Social Support)** | 회복 과정에서 타인과의 연결을 어떻게 활용하는가 | **독립형 (Independent)**<br>혼자만의 시간과 공간에서 회복하는 스타일 | **연결형 (Connected)**<br>사람들과의 상호작용을 통해 회복하는 스타일 |
| **C** | **자기돌봄 (Self-Care)** | 이별 후 자신을 어떻게 돌보는가 | **수용형 (Acceptance)**<br>감정을 있는 그대로 받아들이며 천천히 회복 | **행동형 (Action)**<br>적극적으로 활동하며 새로운 것에 도전하며 회복 |

### 1.3 차원 조합과 유형 분류 원리

3개 차원의 A(0)/B(1) 조합으로 8가지 이별 회복 유형이 생성됩니다.

```
유형 분류 로직:
1. 3개 차원에서 각각 A 또는 B 선택
2. 2³ = 8가지 조합 생성
   - AAA (000): 혼자 조용히 치유하는 유형
   - AAB (001): 혼자서 천천히 성장하는 유형
   - ABA (010): 사람들과 함께하며 내면을 돌보는 유형
   - ABB (011): 친구들과 함께 새로운 시작하는 유형
   - BAA (100): 감정을 표출하며 혼자 회복하는 유형
   - BAB (101): 일기와 운동으로 극복하는 유형
   - BBA (110): 친구들에게 털어놓으며 회복하는 유형
   - BBB (111): 적극적으로 세상 밖으로 나가는 유형

3. 각 유형은 3차원 점수 조합으로 고유하게 결정됨
```

**차원별 점수 합산 방법**:
- 각 문항에서 A 선택 시 해당 차원 +0점, B 선택 시 +1점
- 각 차원별 총점을 계산하여 중앙값(1.5점 또는 2점) 기준으로 A/B 분류
- 3차원 조합(예: E=A, S=B, C=A → ABA)으로 8개 유형 중 하나로 매칭

### 유형 3: 함께하며 마음 돌보기 (ABA - 010)

function determineType(E_score, S_score, C_score) {
  let E = E_score >= 2 ? 'B' : 'A';  // 0~1점: A(내면화), 2~4점: B(외현화)
  let S = S_score >= 2 ? 'B' : 'A';  // 0~1점: A(독립형), 2~3점: B(연결형)
  let C = C_score >= 2 ? 'B' : 'A';  // 0~1점: A(수용형), 2~3점: B(행동형)

  let typeCode = E + S + C;  // 예: "ABB", "BAA" 등

  // 유형 매핑
  const typeMap = {
    'AAA': '혼자만의 치유 시간',

    'ABA': '함께하며 마음 돌보기',

    'BAA': '감정 표출형 회복',

    'BBA': '친구들에게 털어놓기',
    'BBB': '적극적 재기 모드'
  };

  return typeMap[typeCode];
}

3. **자기돌봄 차원 (C)**
   - 문제 중심 대처 vs 감정 중심 대처
   - 적극적 대처가 회복 속도에 영향을 미친다는 긍정심리학 기반
