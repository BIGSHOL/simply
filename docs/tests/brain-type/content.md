# 나의 두뇌 유형은? 🧠

## 테스트 개요

- **테스트 ID**: `brain-type`
- **카테고리**: personality
- **타겟**: 20대 MZ세대
- **톤앤매너**: 흥미로운 과학적 느낌 + 트렌디한 MZ 감성
- **예상 소요시간**: 2~3분
- **주제**: 인지 스타일과 사고방식을 기반으로 개인의 두뇌 작동 방식을 분석

---

## 1. 심리학적 프레임워크

### 이론적 배경

이 테스트는 **인지심리학**과 **사고유형 이론**을 기반으로 설계되었습니다.

- **인지 스타일 이론** (Cognitive Style Theory): 개인이 정보를 인식하고 처리하는 고유한 방식
- **좌뇌/우뇌 이론** (Left-Right Brain Theory): 논리적 사고와 창의적 사고의 균형
- **듀얼 프로세스 이론** (Dual Process Theory): 직관적 처리(System 1)와 분석적 처리(System 2)
- **Sternberg의 사고 유형 이론**: 입법적(창의), 집행적(실행), 사법적(평가) 사고

### 측정 차원 (3축)

본 테스트는 3개의 독립적인 인지 차원을 측정합니다:

| 차원 | 설명 | 측정 범위 |
|------|------|----------|
| **사고방식** (Thinking Mode) | 문제를 접근하는 기본 방식 | 논리형(L) ↔ 직관형(I) |
| **정보처리** (Processing) | 정보를 받아들이고 이해하는 방법 | 분석형(A) ↔ 통합형(S) |
| **문제해결** (Problem Solving) | 실제 문제를 풀어가는 스타일 | 체계형(P) ↔ 창의형(C) |

### 차원 조합 원리

- 각 차원은 **이분법적 선택** (A vs B)으로 측정
- 10개 문항 중 3-4개씩 각 차원을 측정
- 차원별 점수를 합산하여 High/Low 판정
- 3개 차원의 조합으로 **8가지 두뇌 유형** 도출

**조합 공식**:
```
사고방식(L/I) × 정보처리(A/S) × 문제해결(P/C) = 8가지 유형
```

## 2. 결과 유형 (8개)

### 유형 1: 전략가 두뇌
**코드**: `LAP` (Logic-Analytic-Planned)
**한줄설명**: 치밀한 계획으로 세상을 정복하는 전략적 사고자
**키워드**: #체스마스터 #데이터기반 #로드맵장인 #계획충

#### 두뇌 작동 방식
당신의 두뇌는 **논리적 프레임워크 위에서 돌아가는 슈퍼컴퓨터**입니다. 모든 상황을 논리적으로 분해하고, 데이터를 꼼꼼히 분석하며, 체계적인 계획을 세워 실행합니다. "만약 A가 일어나면 B를 하고, B가 실패하면 C로..."라는 시뮬레이션이 머릿속에서 자동 재생됩니다.

#### 사고 성향 분석
- **장기적 시야**: 3년 뒤, 5년 뒤를 내다보며 로드맵을 그립니다
- **리스크 관리**: 모든 변수를 고려해 플랜 B, C까지 준비
- **논리적 설득**: 감보다는 근거와 데이터로 의사결정
- **분석 중독**: 때로는 분석만 하다가 실행 타이밍을 놓칠 수도

#### 강점
- 복잡한 문제를 체계적으로 해결
- 장기 프로젝트를 끝까지 완수하는 끈기
- 팀에서 신뢰받는 안정적인 플래너
- 리스크를 최소화하는 의사결정

#### 약점
- 과도한 분석으로 실행 지연 (분석 마비)
- 돌발 상황에 유연하게 대처하기 어려움
- "일단 해보자" 스타일과 충돌 가능
- 창의적 아이디어보다 검증된 방법 선호

#### 시너지 유형
- **발명가 두뇌(ICP)**: 당신의 체계에 그들의 창의력이 더해지면 완벽
- **중재자 두뇌(ISP)**: 당신의 논리를 부드럽게 전달해주는 파트너

#### 활용 팁
- 기획자, 전략 컨설턴트, 데이터 분석가, 프로젝트 매니저 적합
- "일단 시작하고 보정하기" 마인드도 연습해보세요
- 직관형 친구들과 협업하면 시야가 넓어집니다

### 유형 2: 예술가 두뇌
**코드**: `ISC` (Intuition-Synthetic-Creative)
**한줄설명**: 세상을 감각으로 느끼고 창조하는 자유로운 영혼
**키워드**: #감성충만 #아이디어뱅크 #틀깨기 #예술혼

#### 두뇌 작동 방식
당신의 두뇌는 **무한한 상상력이 흐르는 창작 스튜디오**입니다. 논리보다는 직관, 분석보다는 전체적인 느낌, 계획보다는 영감이 먼저 찾아옵니다. "이게 맞을 것 같아!"라는 느낌으로 움직이며, 기존의 틀을 깨는 새로운 아이디어를 끊임없이 생산합니다.

#### 사고 성향 분석
- **직관적 통찰**: 논리적 근거 없이도 "느낌"으로 답을 찾음
- **전체론적 사고**: 디테일보다 큰 그림과 맥락을 중시
- **창의적 자유**: 규칙과 틀에 갇히는 걸 답답해함
- **즉흥적 실행**: 계획은 대충, 일단 시작하고 보는 스타일

#### 강점
- 아무도 생각 못한 기발한 아이디어 창출
- 감성적 소통으로 사람들의 마음을 움직임
- 변화무쌍한 환경에서도 유연하게 적응
- 예술, 디자인, 콘텐츠 분야에서 빛남

#### 약점
- 체계적 실행이 약해 아이디어만 많고 완성은 어려움
- 디테일한 분석이나 데이터 작업은 지루함
- 마감이나 루틴에 스트레스를 많이 받음
- 논리형 사람들과 "이게 왜 안 돼?"로 충돌

#### 시너지 유형
- **전략가 두뇌(LAP)**: 당신의 아이디어를 현실로 만들어줄 최고의 파트너
- **실행가 두뇌(LSP)**: 당신의 창의력을 체계적으로 실현

#### 활용 팁
- 아티스트, 마케터, 콘텐츠 크리에이터, 브랜드 기획자 적합
- 아이디어 노트를 항상 들고 다니세요 (영감은 갑자기 옴)
- 실행력 강한 파트너와 협업하면 시너지 폭발

### 유형 3: 분석가 두뇌
**코드**: `LAC` (Logic-Analytic-Creative)
**한줄설명**: 논리적 탐구로 혁신을 만드는 과학자형 사고자
**키워드**: #호기심대장 #논리적창의 #문제해결사 #탐구정신

#### 두뇌 작동 방식
당신의 두뇌는 **논리와 창의성이 공존하는 실험실**입니다. 데이터를 철저히 분석하면서도, 기존 방식에 안주하지 않고 새로운 해결책을 찾아냅니다. "왜 이렇게 되는 거지?"라는 질문을 끊임없이 던지며, 인과관계를 밝히는 데 희열을 느낍니다.

#### 사고 성향 분석
- **논리적 호기심**: 현상의 본질과 원리를 파고듦
- **분석적 창의**: 데이터 속에서 새로운 패턴과 인사이트 발견
- **실험적 태도**: 가설을 세우고 검증하는 과정을 즐김
- **지적 자극 추구**: 루틴보다는 새로운 도전에 흥미

#### 강점
- 복잡한 문제의 근본 원인을 찾아냄
- 데이터 기반의 혁신적 솔루션 제시
- 논리와 창의를 동시에 활용하는 균형감
- 연구, 개발, 혁신 분야에서 탁월함

#### 약점
- 지나친 탐구로 실행이 늦어질 수 있음
- "왜?"를 너무 많이 물어서 주변이 지칠 수도
- 체계적 프로세스보다 탐구 자체에 집중
- 감성적 소통보다 논리적 설득 선호

#### 시너지 유형
- **중재자 두뇌(ISP)**: 당신의 논리를 사람들에게 공감 가게 전달
- **실행가 두뇌(LSP)**: 당신의 발견을 실제로 구현

#### 활용 팁
- 연구원, 데이터 사이언티스트, UX 리서처, 혁신 전략가 적합
- 탐구와 실행의 균형을 맞추는 연습이 필요
- "완벽한 답"보다 "빠른 실행" 마인드도 길러보세요

### 유형 4: 발명가 두뇌
**코드**: `ICP` (Intuition-Creative-Planned)
**한줄설명**: 영감을 현실로 만드는 창의적 실행자
**키워드**: #아이디어실현 #미래지향 #혁신가 #체계적창의

#### 두뇌 작동 방식
당신의 두뇌는 **창의성과 실행력이 만난 혁신 공장**입니다. 직관적으로 떠오른 아이디어를 그냥 두지 않고, 구체적인 계획으로 만들어 실현시킵니다. "이거 재밌을 것 같은데?" → "어떻게 만들지?" → "계획 완성!" 순서로 빠르게 진행됩니다.

#### 사고 성향 분석
- **영감형 기획**: 직관적 아이디어를 체계적으로 구조화
- **실현 가능한 창의**: 꿈같은 아이디어가 아닌 실행 가능한 혁신
- **단계적 실행**: 창의적이지만 계획적으로 진행
- **미래 지향**: 트렌드를 읽고 한 발 앞서가는 감각

#### 강점
- 아이디어를 실제로 만들어내는 실행력
- 창의성과 체계성의 완벽한 조화
- 스타트업, 신사업 개발에 최적화
- 트렌드를 선도하는 혁신가

#### 약점
- 지나치게 많은 프로젝트를 동시에 진행
- 디테일한 분석보다 직관에 의존
- "느낌"이 안 좋으면 계획을 갑자기 바꿀 수도
- 논리적 검증 과정을 건너뛰는 경향

#### 시너지 유형
- **전략가 두뇌(LAP)**: 당신의 아이디어에 탄탄한 전략을 더해줌
- **분석가 두뇌(LAC)**: 당신의 직관을 데이터로 검증

#### 활용 팁
- 스타트업 창업자, 프로덕트 매니저, 혁신 기획자 적합
- 논리형 파트너와 협업하면 성공 확률 UP
- 실패를 두려워하지 마세요 - 시도 자체가 자산입니다

### 유형 5: 실행가 두뇌
**코드**: `LSP` (Logic-Synthetic-Planned)
**한줄설명**: 큰 그림을 보며 착실히 실행하는 완성형 인간
**키워드**: #실행력갑 #완성강박 #책임감 #안정추구

#### 두뇌 작동 방식
당신의 두뇌는 **목표를 향해 착실히 나아가는 내비게이션**입니다. 전체 맥락을 이해하고, 논리적으로 우선순위를 정하며, 계획대로 하나씩 체크하며 완성해갑니다. "시작했으면 끝을 본다"가 당신의 모토입니다.

#### 사고 성향 분석
- **전략적 실행**: 큰 그림을 보면서 단계별로 진행
- **논리적 종합**: 흩어진 정보를 하나의 맥락으로 연결
- **완성 집착**: 시작한 일은 반드시 마무리
- **안정 지향**: 검증된 방법과 체계적 프로세스 선호

#### 강점
- 프로젝트를 끝까지 완수하는 강력한 실행력
- 팀에서 가장 믿을 수 있는 마무리 담당
- 복잡한 프로젝트도 체계적으로 관리
- 리더십과 책임감이 강함

#### 약점
- 새로운 시도나 실험보다 안정적 방법 선호
- 창의적 발상이 필요한 순간에 막힐 수 있음
- 계획이 틀어지면 스트레스 과다
- "일단 해보자" 스타일과 충돌 가능

#### 시너지 유형
- **예술가 두뇌(ISC)**: 당신의 실행력에 그들의 창의력이 더해지면 완벽
- **발명가 두뇌(ICP)**: 당신이 그들의 아이디어를 현실로

#### 활용 팁
- 오퍼레이션 매니저, 팀 리더, 운영 기획자 적합
- 가끔은 계획 없이 즉흥적으로 살아보는 것도 좋아요
- 창의형 친구들과 협업하면 시야가 넓어집니다

### 유형 6: 중재자 두뇌
**코드**: `ISP` (Intuition-Synthetic-Planned)
**한줄설명**: 공감과 조율로 팀을 하나로 만드는 감성 리더
**키워드**: #공감능력 #관계지향 #조율왕 #감성리더

#### 두뇌 작동 방식
당신의 두뇌는 **사람들의 감정과 상황을 읽는 레이더**입니다. 직관적으로 분위기를 파악하고, 전체 맥락 속에서 각자의 입장을 이해하며, 모두가 만족할 수 있는 계획을 조율합니다. "이 사람은 왜 저렇게 말했을까?"를 본능적으로 이해합니다.

#### 사고 성향 분석
- **감정적 통찰**: 사람들의 숨겨진 의도와 감정을 파악
- **전체적 조율**: 개별 의견을 모아 하나의 방향으로 정리
- **관계 중심 계획**: 프로세스보다 사람을 먼저 생각
- **조화 추구**: 갈등을 최소화하고 협력을 이끌어냄

#### 강점
- 팀의 분위기를 읽고 갈등을 중재
- 다양한 이해관계를 조율하는 능력
- 감성 리더십으로 팀원들의 신뢰를 얻음
- HR, 팀 빌딩, 협업 프로젝트에 최적

#### 약점
- 논리적 분석이나 데이터 작업은 부담
- 모두를 만족시키려다 결정이 늦어질 수 있음
- 갈등 상황에서 스트레스를 많이 받음
- 자신의 의견보다 타인의 의견을 우선시

#### 시너지 유형
- **전략가 두뇌(LAP)**: 당신의 조율 능력에 그들의 전략이 더해지면 완벽
- **분석가 두뇌(LAC)**: 당신의 감성을 논리로 보완

#### 활용 팁
- HR 매니저, 팀 리더, 기획자, 상담사 적합
- 논리적 근거도 함께 제시하면 설득력 UP
- 자신의 의견도 당당히 표현하는 연습이 필요

---

### 유형 7: 탐험가 두뇌
**코드**: `IAC` (Intuition-Analytic-Creative)
**한줄설명**: 디테일을 탐구하며 새로운 길을 찾는 모험가
**키워드**: #호기심왕 #실험정신 #디테일헌터 #자유로운영혼

#### 두뇌 작동 방식
당신의 두뇌는 **끊임없이 새로운 것을 찾아다니는 탐험가**입니다. 직관적으로 흥미로운 주제를 발견하면, 디테일하게 파고들어 분석하고, 창의적인 방식으로 재해석합니다. "이거 왜 이렇게 돼 있지?" → "한번 파헤쳐보자!" → "오, 이렇게도 할 수 있네!"

#### 사고 성향 분석
- **직관적 탐구**: 느낌으로 흥미를 발견하고 깊이 파고듦
- **분석적 창의**: 디테일 속에서 새로운 패턴 발견
- **실험적 마인드**: 규칙을 깨고 새로운 방법 시도
- **변화 추구**: 루틴보다 새로운 자극을 갈망

#### 강점
- 아무도 주목하지 않은 인사이트 발견
- 기존 방식을 뒤집는 창의적 솔루션 제시
- 다양한 분야를 넘나드는 융합 사고
- 연구, 혁신, 콘텐츠 개발에 탁월

#### 약점
- 흥미가 옮겨가면 프로젝트를 중단할 수도
- 체계적 실행보다 탐구 자체에 집중
- 루틴이나 반복 작업에 극심한 지루함
- 한 우물을 깊이 파기보다 여러 우물을 얕게

#### 시너지 유형
- **실행가 두뇌(LSP)**: 당신의 발견을 체계적으로 완성
- **발명가 두뇌(ICP)**: 서로의 창의력이 시너지

#### 활용 팁
- 리서처, 콘텐츠 크리에이터, 혁신가, 작가 적합
- 한 가지에 집중하는 연습도 필요
- 실행력 강한 파트너와 함께하면 완성도 UP

### 유형 8: 자유영혼 두뇌
**코드**: `IAP` (Intuition-Analytic-Planned)
**한줄설명**: 감각적 통찰로 전략을 짜는 예민한 기획자
**키워드**: #직관적전략 #세심함 #감각파 #계획적즉흥

#### 두뇌 작동 방식
당신의 두뇌는 **직관과 논리가 조화를 이룬 독특한 시스템**입니다. 느낌으로 방향을 잡지만, 디테일을 놓치지 않고 분석하며, 체계적인 계획으로 실행합니다. "이게 뭔가 느낌이 와" → "왜 그런지 분석해보자" → "그럼 이렇게 계획을 세워야겠다"는 흐름으로 사고합니다.

#### 사고 성향 분석
- **감각적 분석**: 직관적으로 느낀 것을 논리적으로 검증
- **전략적 유연성**: 계획은 있지만 상황에 따라 조정
- **예민한 관찰**: 미묘한 변화와 신호를 놓치지 않음
- **균형 감각**: 느낌과 논리, 자유와 체계의 조화

#### 강점
- 직관과 논리를 모두 활용하는 균형감
- 트렌드를 읽고 전략으로 구체화
- 예민한 감각으로 리스크를 사전에 감지
- 기획, 전략, 브랜딩 분야에 최적

#### 약점
- 직관과 분석 사이에서 고민이 많음
- 완벽주의로 실행이 늦어질 수 있음
- 너무 많은 변수를 고려해 결정 지연
- 감성과 논리 사이에서 스트레스

#### 시너지 유형
- **예술가 두뇌(ISC)**: 당신의 전략에 그들의 창의력이 더해지면 완벽
- **실행가 두뇌(LSP)**: 당신의 기획을 착실히 실현

#### 활용 팁
- 브랜드 전략가, 마케팅 기획자, 트렌드 애널리스트 적합
- 때로는 직관을 믿고 빠르게 결정하는 연습도 필요
- 실행형 파트너와 협업하면 완성도 UP

## 4. 점수 산출 로직

### 4.1 차원별 점수 합산

문항 응답을 기반으로 3개 차원의 점수를 각각 합산합니다:

```
사고방식 점수:
- 논리형(L) 점수 = Q1-A + Q5-A + Q7-A + Q10-A (최대 4점)
- 직관형(I) 점수 = Q1-B + Q5-B + Q7-B + Q10-B (최대 4점)

정보처리 점수:
- 분석형(A) 점수 = Q2-A + Q6-A + Q8-A (최대 3점)
- 통합형(S) 점수 = Q2-B + Q6-B + Q8-B (최대 3점)

문제해결 점수:
- 체계형(P) 점수 = Q3-A + Q4-A + Q9-A (최대 3점)
- 창의형(C) 점수 = Q3-B + Q4-B + Q9-B (최대 3점)
```

### 4.2 차원별 유형 결정

각 차원에서 더 높은 점수를 받은 쪽으로 유형을 결정합니다:

| 차원 | 결정 로직 |
|------|----------|
| 사고방식 | Logic(L) 점수 > Intuition(I) 점수 → **L**, 그 외 → **I** |
| 정보처리 | Analytic(A) 점수 > Synthetic(S) 점수 → **A**, 그 외 → **S** |
| 문제해결 | Planned(P) 점수 > Creative(C) 점수 → **P**, 그 외 → **C** |

**동점 처리 규칙**:
- 동점일 경우 후자 선택 (I, S, C)
- 이유: 직관형/통합형/창의형이 더 흥미로운 결과로 인식되는 경향

### 4.3 최종 유형 결정

3개 차원의 조합으로 8가지 유형 중 하나를 결정합니다:

```
최종 유형 코드 = [사고방식] + [정보처리] + [문제해결]

예시:
- L + A + P → LAP (전략가 두뇌)
- I + S + C → ISC (예술가 두뇌)
- L + A + C → LAC (분석가 두뇌)
- I + C + P → ICP (발명가 두뇌)
- L + S + P → LSP (실행가 두뇌)
- I + S + P → ISP (중재자 두뇌)
- I + A + C → IAC (탐험가 두뇌)
- I + A + P → IAP (자유영혼 두뇌)
```

### 4.4 유형별 매핑 테이블

| 코드 | 사고방식 | 정보처리 | 문제해결 | 유형명 |
|------|----------|----------|----------|--------|
| LAP | 논리형(L) | 분석형(A) | 체계형(P) | 전략가 두뇌 |
| ISC | 직관형(I) | 통합형(S) | 창의형(C) | 예술가 두뇌 |
| LAC | 논리형(L) | 분석형(A) | 창의형(C) | 분석가 두뇌 |
| ICP | 직관형(I) | 창의형(C) | 체계형(P) | 발명가 두뇌 |
| LSP | 논리형(L) | 통합형(S) | 체계형(P) | 실행가 두뇌 |
| ISP | 직관형(I) | 통합형(S) | 체계형(P) | 중재자 두뇌 |
| IAC | 직관형(I) | 분석형(A) | 창의형(C) | 탐험가 두뇌 |
| IAP | 직관형(I) | 분석형(A) | 체계형(P) | 자유영혼 두뇌 |

### 4.5 구현 예시 (의사코드)

```javascript
function calculateBrainType(answers) {
  // 1. 차원별 점수 합산
  const logicScore = answers[0].A + answers[4].A + answers[6].A + answers[9].A;
  const intuitionScore = answers[0].B + answers[4].B + answers[6].B + answers[9].B;

  const analyticScore = answers[1].A + answers[5].A + answers[7].A;
  const syntheticScore = answers[1].B + answers[5].B + answers[7].B;

  const plannedScore = answers[2].A + answers[3].A + answers[8].A;
  const creativeScore = answers[2].B + answers[3].B + answers[8].B;

  // 2. 차원별 유형 결정
  const thinkingMode = logicScore > intuitionScore ? 'L' : 'I';
  const processing = analyticScore > syntheticScore ? 'A' : 'S';
  const problemSolving = plannedScore > creativeScore ? 'P' : 'C';

  // 3. 최종 유형 코드
  const brainTypeCode = thinkingMode + processing + problemSolving;

  // 4. 유형 정보 반환
  return getBrainTypeInfo(brainTypeCode);
}
```
