> **테스트 ID**: zombie-survival
> **테스트명**: 좀비 아포칼립스 생존 유형

## 1. 심리학적 프레임워크

### 1.1 이론적 배경

본 테스트는 극한 상황에서의 인간 행동 패턴을 분석하는 위기 대처 심리학을 기반으로 설계되었습니다.

#### 1) 위기 상황 대처 이론 (Stress & Coping Theory)
- **Richard Lazarus & Susan Folkman**의 연구 기반
- 스트레스 상황에서의 인지적 평가와 대처 전략
- 문제 중심 대처(Problem-focused) vs 감정 중심 대처(Emotion-focused)
- 본 테스트에서는 **의사결정** 차원에 반영

#### 2) 생존 본능과 행동 패턴
- 싸우기(Fight), 도망치기(Flight), 얼어붙기(Freeze) 반응
- 극한 상황에서의 에너지 배분 전략
- 본 테스트에서는 **생존전략** 차원에 반영

#### 3) 집단 역학 이론 (Group Dynamics)
- **Kurt Lewin**의 집단 행동 연구
- 위기 상황에서의 협력 vs 개인주의
- 리더십과 팔로워십의 역할 분담
- 본 테스트에서는 **사회성** 차원에 반영

#### 4) 성격 유형론 (Personality Typology)
- MBTI의 사고(T) vs 감정(F), 외향(E) vs 내향(I) 축 응용
- 행동 패턴의 일관성과 예측 가능성
- 3축 조합으로 8가지 서바이벌 페르소나 도출

### 1.2 측정 차원 정의 (3축)

| 차원 코드 | 차원명 | 정의 | A방향 (0점) | B방향 (1점) |
|----------|--------|------|------------|------------|
| **DM** | 의사결정<br>(Decision Making) | 위기 상황에서 판단과 선택을 내리는 방식 | **이성적 (Logic)**<br>데이터와 논리로 판단,<br>냉철한 분석가형 | **직관적 (Instinct)**<br>본능과 감각으로 판단,<br>빠른 직감형 |
| **SS** | 생존전략<br>(Survival Strategy) | 위험에 대응하는 행동 패턴 | **방어형 (Defensive)**<br>안전 확보 우선,<br>은신과 회피 전략 | **공격형 (Offensive)**<br>위험 제거 우선,<br>정면돌파 전략 |
| **SC** | 사회성<br>(Social Connection) | 타인과의 협력과 관계 형성 방식 | **개인주의 (Solo)**<br>혼자서 생존,<br>독립적 행동 | **집단주의 (Team)**<br>함께 생존,<br>협력적 행동 |

### 1.3 차원 조합과 유형 분류 원리

3개 차원의 A(0점)/B(1점) 조합으로 8가지 좀비 서바이벌 유형이 도출됩니다.

```
유형 분류 로직 (3비트 이진수):
- DM(의사결정): A=0(이성), B=1(직관)
- SS(생존전략): A=0(방어), B=1(공격)
- SC(사회성): A=0(개인), B=1(집단)

예시:
- 000(AAA) = 이성+방어+개인 → 냉철한 생존주의자
- 111(BBB) = 직관+공격+집단 → 카리스마 리더
- 101(BAB) = 직관+방어+집단 → 파티 수호자
```

**유형 결정 로직**:
1. 각 차원별 문항 점수를 합산 (차원당 3-4개 문항)
2. 차원별 중앙값(1.5점 또는 2점) 기준으로 A/B 분류
3. 3축 조합으로 8개 유형 중 하나로 매칭

## 2. 8개 결과 유형 설계

### 유형 1: 냉철한 생존주의자 (AAA)
**조합**: 이성적 + 방어형 + 개인주의

| 항목 | 내용 |
|------|------|
| **유형 코드** | TYPE_AAA |
| **유형명** | 냉철한 생존주의자 (Cold Survivalist) |
| **한줄 설명** | 감정은 사치, 생존만이 진리. 혼자서도 끝까지 살아남는다 |
| **핵심 키워드** | #냉정한판단 #솔로플레이 #생존마스터 #계산적행동 |

#### 좀비 세계에서의 역할
당신은 좀비 아포칼립스에서 **혼자서도 무섭게 잘 살아남는 독립 생존 전문가**입니다. 다른 사람들이 패닉에 빠져 있을 때, 당신은 이미 물자를 계산하고 안전한 은신처를 확보했을 거예요. "저 건물 2층은 탈출로가 없으니까 패스"하는 식으로 항상 냉정하게 판단하죠.

좀비 드라마에서 주인공 파티를 만나도 "같이 가면 식량 소비가 2배인데?"라고 계산부터 하는 타입. 하지만 그 냉철함 덕분에 생존율은 최상위권! 누가 뭐래도 당신은 엔딩 크레딧까지 살아남을 확률이 가장 높습니다.

#### 생존 성향 분석
- **의사결정**: 감정보다 데이터. "저 좀비는 시속 3km, 내 체력으론 30분 도주 가능" 같은 계산이 머릿속에서 자동으로 돌아갑니다.
- **생존전략**: 정면승부는 비효율적. 몰래 숨어서 안전하게 이동하고, 불필요한 전투는 회피합니다.
- **사회성**: 팀플보다 솔플이 편해요. 다른 사람 챙기면 내 생존 확률만 낮아진다는 현실주의자.

#### 생존 강점
1. **냉정한 상황 판단**: 패닉 상태에 빠지지 않고 최적의 선택을 내립니다
2. **효율적 자원 관리**: 물자 하나도 낭비 없이 분배하고 계획적으로 사용합니다
3. **독립적 생존 능력**: 누구에게도 의지하지 않고 혼자서도 끝까지 버팁니다
4. **위험 회피 전문가**: 불필요한 리스크를 피하고 안전 루트만 선택합니다

#### 생존 약점
1. **타인과의 협력 부족**: 때로는 팀워크가 더 큰 힘이 될 수 있다는 걸 놓칠 수 있어요
2. **감정적 유대감 결여**: 동료를 버릴 수 있다는 인식 때문에 신뢰받기 어려울 수 있습니다
3. **과도한 신중함**: 너무 안전만 추구하다 보면 중요한 기회를 놓칠 수도 있어요

#### 파티원으로서 잘 맞는 유형
- **전술 참모형**: 당신처럼 논리적이지만 팀플레이를 하는 유형과는 시너지가 좋아요
- **카리스마 리더**: 당신의 전략적 사고와 리더의 추진력이 만나면 최강 조합!

#### 현생 적용 조언
직장에서는 프로젝트 리스크 관리자나 데이터 분석가처럼 냉정한 판단이 필요한 역할에 강점을 보여요. 하지만 가끔은 감정도 중요한 데이터라는 걸 기억하세요. 커피 한 잔 마시며 동료와 수다 떠는 것도 생존 전략이 될 수 있답니다!

### 유형 2: 전술 참모형 (AAB)
**조합**: 이성적 + 방어형 + 집단주의

| 항목 | 내용 |
|------|------|
| **유형 코드** | TYPE_AAB |
| **유형명** | 전술 참모형 (Strategic Advisor) |
| **한줄 설명** | 팀의 두뇌, 완벽한 작전으로 모두를 살린다 |
| **핵심 키워드** | #전략가 #팀워크 #안전제일 #계획형인간 |

#### 좀비 세계에서의 역할
당신은 생존자 그룹의 **두뇌이자 전략 담당 참모**입니다. "좀비가 저쪽에서 오니까 우리는 이 루트로 우회해서 물자 확보하고, B팀은 대기조로..." 같은 완벽한 작전을 짜는 게 당신의 특기! 리더가 "가자!"라고 하면 "잠깐, 지도 보고 최적 루트 계산부터 해요"라고 말리는 타입이죠.

좀비 영화로 치면 그 똑똑한 안경 쓴 캐릭터가 바로 당신! 혼자서도 살 수 있지만, 팀의 생존율을 극대화하는 게 더 효율적이라는 걸 아는 합리주의자예요. 당신 덕분에 파티원들은 위험을 최소화하면서 미션을 완수합니다.

#### 생존 성향 분석
- **의사결정**: 데이터 기반 전략 수립. 지도, 날씨, 좀비 이동 패턴까지 모든 변수를 고려합니다.
- **생존전략**: 정면 충돌은 최후의 수단. 언제나 Plan A, B, C까지 준비하는 안전 우선주의.
- **사회성**: 팀플레이가 생존 확률을 높인다는 걸 아는 협력주의자. 함께 살고 함께 살아남습니다.

#### 생존 강점
1. **완벽한 전략 기획**: 모든 시나리오를 예측하고 대비책을 마련합니다
2. **팀 생존율 극대화**: 구성원 각자의 강점을 파악해 최적 배치를 합니다
3. **리스크 관리 능력**: 위험 요소를 사전에 차단하고 안전한 경로를 제시합니다
4. **냉정한 조율자**: 감정적 갈등을 논리로 중재하고 팀을 하나로 모읍니다

#### 생존 약점
1. **과도한 계획 집착**: 계획이 틀어지면 당황할 수 있어요. 가끔은 즉흥도 필요해요
2. **행동력 부족**: 분석만 하다가 타이밍을 놓칠 수 있습니다
3. **리더십 발휘 어려움**: 전략은 완벽하지만 추진력 있는 리더가 함께해야 빛을 발해요

#### 파티원으로서 잘 맞는 유형
- **카리스마 리더**: 당신의 전략 + 리더의 실행력 = 최강 조합
- **전투 마스터**: 당신의 계획을 현장에서 완벽하게 실행해줄 전사 타입

#### 현생 적용 조언
기획자, 전략 컨설턴트, 프로젝트 매니저처럼 체계적 사고가 필요한 분야에서 빛을 발해요. 하지만 가끔은 계획 없이 즉흥적으로 움직이는 것도 나쁘지 않답니다. 친구가 "그냥 가보자"고 할 때 한 번쯤은 따라가 보세요!

### 유형 3: 게릴라 파이터 (ABA)
**조합**: 이성적 + 공격형 + 개인주의

| 항목 | 내용 |
|------|------|
| **유형 코드** | TYPE_ABA |
| **유형명** | 게릴라 파이터 (Guerrilla Fighter) |
| **한줄 설명** | 혼자서 좀비 소탕, 조용하지만 치명적인 원맨아미 |
| **핵심 키워드** | #원맨아미 #전투기계 #냉정한살수 #솔로헌터 |

#### 좀비 세계에서의 역할
당신은 **혼자서 좀비를 사냥하는 고독한 전사**입니다. 다른 사람들이 숨어 있을 때, 당신은 이미 무기를 들고 좀비를 제거하러 나섰을 거예요. "저 좀비는 목 관절이 약하니까 저걸 노리면 1초 컷"처럼 약점을 정확히 파악하고 효율적으로 처치하는 게 당신의 스타일.

좀비 게임으로 치면 혼자서 하드코어 모드 클리어하는 그런 플레이어! 팀플레이는 귀찮고, 내 페이스대로 움직이는 게 더 효율적이라고 생각하죠. 조용히 등장해서 좀비를 쓸어버리고 조용히 사라지는 다크히어로 같은 존재예요.

#### 생존 성향 분석
- **의사결정**: 전투 시뮬레이션을 머릿속으로 돌려요. "좀비 3마리, 무기 내구도 70%, 승산 90%"
- **생존전략**: 도망치는 건 비효율적. 위협은 직접 제거하는 게 장기적으로 안전합니다.
- **사회성**: 혼자가 편해요. 다른 사람 챙기면 전투 효율만 떨어진다고 생각합니다.

#### 생존 강점
1. **전투 효율성**: 최소한의 에너지로 최대한의 적을 제압합니다
2. **냉정한 판단력**: 전투 중에도 패닉하지 않고 약점을 파악합니다
3. **자립적 생존**: 누구의 도움 없이도 혼자서 위협을 처리합니다
4. **전술적 사고**: 무기 선택부터 공격 타이밍까지 모든 게 계산적입니다

#### 생존 약점
1. **고립 위험**: 혼자서는 감당 못 할 상황에서도 도움을 요청하지 않을 수 있어요
2. **과신**: 자신의 전투력을 과대평가해서 위험에 빠질 수 있습니다
3. **팀워크 부재**: 협력했다면 더 쉽게 해결될 문제를 혼자 끙끙댈 수 있어요

#### 파티원으로서 잘 맞는 유형
- **전술 참모형**: 당신의 전투력 + 참모의 전략 = 완벽한 미션 수행
- **파티 수호자**: 당신이 공격할 때 뒤를 지켜줄 수 있는 방어형 파트너

#### 현생 적용 조언
개발자, 프리랜서, 1인 사업가처럼 독립적으로 일하는 분야에서 강점을 보여요. 혼자서도 문제를 해결하는 능력이 뛰어나지만, 가끔은 팀원과 협업하면 더 큰 성과를 낼 수 있다는 걸 기억하세요!

### 유형 4: 전투 마스터 (ABB)
**조합**: 이성적 + 공격형 + 집단주의

| 항목 | 내용 |
|------|------|
| **유형 코드** | TYPE_ABB |
| **유형명** | 전투 마스터 (Combat Master) |
| **한줄 설명** | 팀의 검과 방패, 전장에서 빛나는 전술 리더 |
| **핵심 키워드** | #전투대장 #팀전투 #전술리더 #신뢰의아이콘 |

#### 좀비 세계에서의 역할
당신은 생존자 그룹의 **전투 리더이자 최강 전력**입니다. "내가 선두에서 좀비 막을 테니까 다들 내 뒤에서 안전하게 이동해!"라고 외치는 든든한 존재죠. 단순히 힘만 센 게 아니라, 전투 상황을 분석하고 팀원들을 효율적으로 배치하는 전술적 사고까지 갖췄어요.

좀비 드라마에서 주인공이 위기에 처했을 때 "내가 시간 벌게, 너희는 먼저 가!"라고 외치는 그 멋진 캐릭터가 바로 당신! 혼자서도 싸울 수 있지만, 동료를 지키면서 싸울 때 진짜 실력이 나와요. 팀원들은 당신만 있으면 안심하고 미션을 수행합니다.

#### 생존 성향 분석
- **의사결정**: 전투 경험과 데이터를 바탕으로 최적의 전술을 선택합니다.
- **생존전략**: 공격이 최선의 방어. 위협을 제거해야 팀이 안전합니다.
- **사회성**: 동료와 함께 싸우는 게 더 강하다는 걸 알아요. 팀을 지키는 게 곧 내 생존입니다.

#### 생존 강점
1. **뛰어난 전투 능력**: 좀비와의 교전에서 팀의 승리를 이끕니다
2. **전술적 리더십**: 전투 중 팀원들을 효율적으로 지휘합니다
3. **희생 정신**: 동료를 지키기 위해 위험을 감수할 수 있습니다
4. **냉정한 전장 판단**: 감정에 흔들리지 않고 최선의 전술을 구사합니다

#### 생존 약점
1. **과도한 책임감**: 모든 걸 혼자 떠안다가 무리할 수 있어요
2. **전투 의존**: 전투 외의 문제(협상, 자원 관리)에서는 약할 수 있습니다
3. **번아웃 위험**: 항상 선두에서 싸우다 보면 체력적 한계가 올 수 있어요

#### 파티원으로서 잘 맞는 유형
- **전술 참모형**: 참모의 전략을 현장에서 완벽하게 실행합니다
- **생존 코디네이터**: 당신이 싸우는 동안 물자와 의료를 책임져줄 파트너

#### 현생 적용 조언
팀장, 현장 관리자, 소방관처럼 위기 상황에서 리더십을 발휘하는 분야에서 빛나요. 하지만 가끔은 다른 사람에게 책임을 나눠주고 쉬는 것도 중요해요. 슈퍼히어로도 휴식은 필요하답니다!

### 유형 5: 야생 생존왕 (BAA)
**조합**: 직관적 + 방어형 + 개인주의

| 항목 | 내용 |
|------|------|
| **유형 코드** | TYPE_BAA |
| **유형명** | 야생 생존왕 (Wilderness Survivor) |
| **한줄 설명** | 본능으로 위험을 피하고, 자연 속에서 홀로 살아남는다 |
| **핵심 키워드** | #생존본능 #야생적응 #은신고수 #자연친화 |

#### 좀비 세계에서의 역할
당신은 **도시를 벗어나 야생에서 홀로 생존하는 자연주의자**입니다. "이 버섯은 먹을 수 있고, 저 발자국은 좀비 아니라 사슴이야"처럼 본능적으로 환경을 읽어내는 능력이 탁월해요. 다른 사람들이 마트에서 물자를 찾고 있을 때, 당신은 이미 산 속에 은신처를 만들고 덫을 놓았을 거예요.

좀비 드라마에서 시즌 후반에 등장하는 "산에 숨어 살다가 우연히 주인공 일행을 발견한 은둔자" 포지션! 혼자서도 끄떡없이 잘 살고 있어서 주인공들이 "어떻게 혼자 살았어요?"라고 물어보는 그런 캐릭터예요.

#### 생존 성향 분석
- **의사결정**: 머리보다 몸이 먼저 반응해요. "위험해!"라는 느낌이 오면 즉시 회피합니다.
- **생존전략**: 싸우는 것보다 숨는 게 낫죠. 좀비 눈에 안 띄는 게 최고의 생존법입니다.
- **사회성**: 혼자가 편하고, 다른 사람과 있으면 오히려 불안해요.

#### 생존 강점
1. **뛰어난 위험 감지**: 육감으로 위험을 미리 알아채고 피합니다
2. **자연 친화력**: 야생에서 식량과 물을 구하는 능력이 탁월합니다
3. **은신 기술**: 좀비의 시야와 후각을 피해 완벽하게 숨습니다
4. **자립적 생존**: 도시 인프라 없이도 혼자서 무한정 버틸 수 있어요

#### 생존 약점
1. **사회성 부족**: 생존자 그룹과 합류해도 적응하기 어려워요
2. **자원 제한**: 야생에서만 생존할 수 있어 물자가 필요하면 곤란합니다
3. **고립감**: 장기적으로 혼자 있으면 정신 건강에 영향을 받을 수 있어요

#### 파티원으로서 잘 맞는 유형
- **생존 코디네이터**: 당신의 야생 지식 + 코디네이터의 조직력 = 완벽한 베이스캠프
- **파티 수호자**: 당신이 안전한 곳을 찾으면 그들이 그곳을 지켜줍니다

#### 현생 적용 조언
야외 활동가, 환경 운동가, 자급자족 농부처럼 자연과 가까운 일을 할 때 행복해요. 하지만 가끔은 사람들과 어울리는 것도 나쁘지 않아요. 캠핑장에서 옆 텐트 사람들과 인사해보세요!

### 유형 6: 파티 수호자 (BAB)
**조합**: 직관적 + 방어형 + 집단주의

| 항목 | 내용 |
|------|------|
| **유형 코드** | TYPE_BAB |
| **유형명** | 파티 수호자 (Party Guardian) |
| **한줄 설명** | 동료의 안전이 최우선, 든든한 방패막이 |
| **핵심 키워드** | #수호자 #희생정신 #팀지킴이 #따뜻한마음 |

#### 좀비 세계에서의 역할
당신은 생존자 그룹의 **수호천사이자 든든한 방패**입니다. "다들 내 뒤로! 내가 막을게!"라고 외치며 동료들을 지키는 게 당신의 본능이에요. 좀비가 나타나면 자신보다 약한 동료들을 먼저 대피시키고, 위험한 임무는 자신이 먼저 나서는 희생 정신의 화신이죠.

좀비 드라마에서 "나는 괜찮아, 너희는 먼저 가!"라고 외치는 감동적인 장면의 주인공! 육감으로 위험을 감지하면 즉시 동료들을 안전한 곳으로 대피시키고, 본인은 뒤에 남아서 시간을 버는 타입이에요. 팀원들은 당신을 가장 신뢰하고 의지합니다.

#### 생존 성향 분석
- **의사결정**: "위험한 느낌이 들어"라는 직감을 믿고 즉시 대피 신호를 냅니다.
- **생존전략**: 싸우기보다 팀원들을 안전하게 지키는 게 우선. 방어와 보호에 집중합니다.
- **사회성**: 혼자보다 함께가 강하다는 걸 알아요. 동료를 지키는 게 곧 자신의 생존입니다.

#### 생존 강점
1. **뛰어난 위험 감지**: 직감으로 위험을 미리 알아채고 팀을 지킵니다
2. **희생 정신**: 자신을 희생해서라도 동료를 구합니다
3. **신뢰의 중심**: 팀원들이 가장 의지하는 존재입니다
4. **방어 전문가**: 안전한 경로를 찾고 팀을 보호하는 능력이 탁월합니다

#### 생존 약점
1. **과도한 희생**: 자신을 너무 돌보지 않아 위험에 빠질 수 있어요
2. **공격력 부족**: 방어는 잘하지만 적극적으로 위협을 제거하는 건 약합니다
3. **감정적 부담**: 동료가 다치면 자책하며 심리적으로 무너질 수 있어요

#### 파티원으로서 잘 맞는 유형
- **전투 마스터**: 당신이 방어할 때 그들이 공격해줍니다
- **카리스마 리더**: 리더의 결단 + 당신의 수호 = 안전한 팀 운영

#### 현생 적용 조언
간호사, 교사, 사회복지사처럼 타인을 돌보는 일에서 보람을 느껴요. 하지만 가끔은 자신도 돌봐야 해요. "내가 건강해야 남도 도울 수 있다"는 걸 기억하세요!

### 유형 7: 무법자 서바이버 (BBA)

좀비 영화에서 홀로 등장해서 좀비들을 쓸어버리고 사라지는 미스터리한 캐릭터! 다른 생존자들이 "저 사람 뭐야?"라고 수근거리지만, 당신은 관심 없어요. 혼자서 위험을 즐기며 자유롭게 살아가는 게 최고니까요.

#### 생존 성향 분석
- **의사결정**: 생각보다 행동이 빨라요. "일단 해보고 안 되면 다른 거 하지 뭐"
- **생존전략**: 피하는 것보다 정면돌파가 짜릿하죠. 위험? 그게 더 재미있는데?
- **사회성**: 혼자가 편해요. 다른 사람 눈치 보면서 움직이는 건 답답합니다.

#### 생존 강점
1. **뛰어난 순발력**: 예상치 못한 상황에서도 즉시 대응합니다
2. **강력한 전투력**: 본능적으로 좀비의 약점을 파악하고 공격합니다
3. **자유로운 행동**: 규칙에 얽매이지 않아 창의적인 해결책을 찾습니다
4. **두려움 없음**: 위험을 즐기며 남들이 못 하는 걸 해냅니다

#### 생존 약점
1. **무모함**: 본능만 믿다가 위험한 상황에 빠질 수 있어요
2. **계획 부재**: 즉흥적으로만 행동하다 보면 장기 생존에 불리합니다
3. **고립**: 협력할 수 있는 상황에서도 혼자 행동해서 손해를 볼 수 있어요

#### 파티원으로서 잘 맞는 유형
- **전술 참모형**: 당신의 행동력 + 참모의 전략 = 예상 밖의 성공
- **파티 수호자**: 당신이 돌진할 때 뒤를 지켜줄 수 있는 파트너

#### 현생 적용 조언
창업가, 익스트림 스포츠 선수, 프리랜서처럼 자유롭고 도전적인 일을 할 때 빛나요. 하지만 가끔은 계획도 필요해요. 보험 하나쯤은 들어두는 게 어때요?

#### 생존 약점

2. **직관 의존**: 본능이 틀릴 수도 있다는 걸 인정하기 어려워요
3. **번아웃**: 항상 앞장서다 보면 체력적, 정신적으로 지칠 수 있습니다

#### 파티원으로서 잘 맞는 유형

CEO, 정치인, 팀장처럼 사람들을 이끄는 역할에서 빛을 발해요. 하지만 가끔은 팀원들에게 책임을 나눠주고 쉬는 것도 중요해요. 슈퍼히어로에게도 휴식은 필요하답니다!

**점수 계산 예시**:
```
사용자가 다음과 같이 선택했다면:
Q1: B(1점), Q2: A(0점), Q3: B(1점)
Q4: A(0점), Q5: A(0점), Q6: B(1점)
Q7: B(1점), Q8: B(1점), Q9: B(1점)
Q10: A(0점)

→ DM = Q1(1) + Q4(0) + Q8(1) = 2점
→ SS = Q2(0) + Q5(0) + Q7(1) + Q10(0) = 1점
→ SC = Q3(1) + Q6(1) + Q9(1) = 3점
```

### 4.2 H/L 분류 기준선

각 차원의 중앙값을 기준으로 High/Low를 분류합니다.

| 차원 | 최대 점수 | 중앙값 | 분류 기준 |
|------|----------|--------|----------|
| DM | 3점 | 1.5점 | 0-1점: A(이성적), 2-3점: B(직관적) |
| SS | 4점 | 2점 | 0-2점: A(방어형), 3-4점: B(공격형) |

**분류 로직**:
```
DM 차원:
  if (DM점수 <= 1) → A (이성적, Logic)
  else → B (직관적, Instinct)

SS 차원:
  if (SS점수 <= 2) → A (방어형, Defensive)
  else → B (공격형, Offensive)

SC 차원:
  if (SC점수 <= 1) → A (개인주의, Solo)
  else → B (집단주의, Team)
```

### 4.3 유형 결정 로직

3개 차원의 A/B 조합으로 8가지 유형을 결정합니다.

```javascript
function determineType(dmScore, ssScore, scScore) {
  const dm = dmScore <= 1 ? 'A' : 'B';  // 의사결정
  const ss = ssScore <= 2 ? 'A' : 'B';  // 생존전략
  const sc = scScore <= 1 ? 'A' : 'B';  // 사회성

  const combination = dm + ss + sc;  // 예: "AAB", "BBB" 등

  const typeMap = {
    'AAA': 'TYPE_AAA',  // 냉철한 생존주의자
    'AAB': 'TYPE_AAB',  // 전술 참모형
    'ABA': 'TYPE_ABA',  // 게릴라 파이터
    'ABB': 'TYPE_ABB',  // 전투 마스터
    'BAA': 'TYPE_BAA',  // 야생 생존왕
    'BAB': 'TYPE_BAB',  // 파티 수호자
    'BBA': 'TYPE_BBA',  // 무법자 서바이버
    'BBB': 'TYPE_BBB'   // 카리스마 리더
  };

  return typeMap[combination];
}
```

```
조합: AAA → TYPE_AAA (냉철한 생존주의자)
```

**예시 3**: 모든 B 선택 (DM=3, SS=4, SC=3)
