## 1. 심리학적 프레임워크

### 이론적 배경

이 테스트는 다음의 심리학적 개념을 활용합니다:

1. **긍정심리학 (Positive Psychology)**
   - 개인의 강점과 긍정적 정서에 초점
   - 모든 결과를 긍정적이고 고무적인 톤으로 제시
   - 자기효능감 증진을 위한 구체적 행동 제안

2. **자기효능감 이론 (Self-Efficacy Theory)**
   - 오늘 하루를 긍정적으로 시작할 수 있는 심리적 동기 부여
   - "오늘 하면 좋은 것" 제시로 행동 유도
   - 성공 경험 예측을 통한 자신감 향상

3. **바넘 효과 (Barnum Effect)**
   - 보편적이지만 개인화된 느낌을 주는 운세 표현
   - 누구나 공감할 수 있는 일상적 상황 활용
   - 긍정적 해석으로 수용도 증가

4. **상황 선호도와 기분 상태 측정**
   - 현재 심리 상태를 반영한 운세 제공
   - 최근 기분, 선호 상황을 통해 개인의 에너지 수준, 대인관계 성향, 감정 패턴 파악

### 측정 차원 3축 (A/B 이지선다 구조)

| 차원 코드 | 차원명 | 정의 | A방향 (0점) | B방향 (1점) |
|----------|--------|------|------------|------------|
| **E** | 에너지 방향 | 오늘 하루 에너지를 어디서 얻고 어떻게 쓰는가 | 내향적 (Inner) - 혼자 충전, 사색 선호 | 외향적 (Outer) - 사람과 만남, 활동적 |
| **F** | 운의 흐름 | 행운이 찾아오는 방식과 대응 스타일 | 안정 지향 (Stable) - 조용한 행운, 점진적 개선 | 도전 지향 (Dynamic) - 극적 변화, 새로운 시도 |
| **M** | 감성 모드 | 오늘 의사결정과 감정 표현 방식 | 이성적 (Logic) - 논리적 판단, 현실적 사고 | 감성적 (Emotion) - 직관적 판단, 감정 중시 |

### 차원 조합과 유형 분류 원리

**3축 이진 조합 → 2³ = 8개 유형**

각 차원에서 A(0점) 또는 B(1점)을 선택하며, 총 10문항 중:
- E축 측정 문항: 3-4개
- F축 측정 문항: 3-4개
- M축 측정 문항: 2-3개

차원별 점수 합산 후 중앙값(50%) 기준으로 H(High)/L(Low) 분류:
- E축: 0-1점 = Inner (I), 2점 이상 = Outer (O)
- F축: 0-1점 = Stable (S), 2점 이상 = Dynamic (D)
- M축: 0점 = Logic (L), 1점 이상 = Emotion (E)

**유형 코드 예시**:
- ISL = 내향 + 안정 + 이성 → "조용한 성장 운"
- ODE = 외향 + 도전 + 감성 → "대박 로맨스 운"

### 유형별 상세 결과 콘텐츠

#### 유형 1: ISL - 조용한 성장 운

**오늘의 전반적 운세**
오늘은 조용하지만 확실한 성장의 날입니다. 화려한 이벤트보다는 차근차근 쌓아가는 과정에서 진짜 행운이 숨어있어요. 혼자만의 시간을 가지며 계획을 세우거나, 미뤄뒀던 공부/독서를 하면 예상보다 큰 성취감을 느낄 거예요. 소소하지만 확실한 행복이 찾아오는 하루!

**세부 운세**
- 연애운: 급하게 다가가기보단 천천히 신뢰를 쌓는 게 좋아요. 조용한 관심이 더 효과적.
- 금전운: 충동구매 대신 저축/투자 공부하기 좋은 날. 장기적 재테크 시작 타이밍!
- 건강운: 요가, 명상, 가벼운 산책으로 몸과 마음을 정리하면 컨디션 업!

**오늘의 럭키 포인트**
- 럭키 컬러: 베이지, 아이보리 (차분한 톤)
- 럭키 아이템: 노트, 펜, 따뜻한 차
- 럭키 넘버: 3, 7
- 럭키 플레이스: 도서관, 카페, 집 책상

**오늘 하면 좋은 것**
- 미뤄뒀던 목표 재정리하기
- 자기계발 강의 하나 듣기
- 조용한 곳에서 사색 타임 갖기
- 일기 쓰기

**오늘 피하면 좋은 것**
- 시끄러운 술자리
- 충동적인 큰 결정
- 멀티태스킹 (한 번에 하나씩!)

**오늘의 응원 메시지**
"조용한 강물이 깊이 흐른다"는 말 알죠? 오늘의 당신이 딱 그래요. 티 나지 않게 쌓이는 노력이 나중에 빛을 발할 거예요. 혼자만의 시간을 소중히 여기고, 내면의 목소리에 귀 기울여보세요!

#### 유형 2: ISE - 힐링 에너지 운

**오늘의 전반적 운세**
오늘은 마음이 따뜻해지는 힐링의 날입니다. 감성이 풍부해져서 평소엔 그냥 지나쳤을 작은 것들에서 큰 위로를 받을 수 있어요. 좋아하는 음악 듣고, 좋아하는 영화 보고, 좋아하는 간식 먹으면서 나를 충전하는 시간을 가져보세요. 감정을 솔직하게 표현하면 예상치 못한 공감과 응원을 받을 수 있어요.

**세부 운세**
- 연애운: 솔직한 감정 표현이 관계를 더 깊게 만들어요. 속마음 털어놓기 좋은 날!
- 금전운: 자기 자신에게 투자하는 소비는 OK! 마음을 채워주는 것에 돈 쓰세요.
- 건강운: 감정 해소가 중요. 좋아하는 취미 활동으로 스트레스 날려버리기!

**오늘의 럭키 포인트**
- 럭키 컬러: 파스텔 핑크, 라벤더
- 럭키 아이템: 향초, 플레이리스트, 따뜻한 담요
- 럭키 넘버: 2, 6
- 럭키 플레이스: 집, 아늑한 카페, 공원 벤치

**오늘 하면 좋은 것**
- 좋아하는 영화/드라마 정주행
- 감성 플레이리스트 만들기
- 일기장에 감정 솔직하게 적기
- 힐링템 소비 (향초, 목욕용품 등)

**오늘 피하면 좋은 것**
- 복잡한 인간관계 문제 해결 시도
- 무리한 스케줄
- 감정 억누르기

**오늘의 응원 메시지**
오늘은 그냥 나를 위한 날로 만들어보세요. 생산성 안 높아도 괜찮아요. 감정을 충전하는 것도 중요한 성장이니까요. 오늘 당신이 느끼는 모든 감정은 소중하고, 당신은 그 감정을 느낄 자격이 충분해요!

#### 유형 3: IDL - 전략적 승부 운

**오늘의 전반적 운세**
오늘은 혼자만의 승부수를 띄우기 좋은 날입니다! 계획했던 일이 술술 풀리고, 집중력이 최상이에요. 다른 사람 눈치 안 보고 내 페이스대로 밀고 나가면 큰 성과를 낼 수 있어요. 전략적으로 움직이고, 리스크를 계산하며 도전하면 예상보다 훨씬 좋은 결과가 나올 거예요.

**세부 운세**
- 연애운: 밀당 전략이 통하는 날. 너무 적극적이기보단 여유 있게 행동해보세요.
- 금전운: 투자/재테크 공부한 거 실전 투입하기 좋은 날. 계산된 승부 추천!
- 건강운: 혼자 하는 운동(홈트, 러닝)에 집중하면 효과 만점!

**오늘의 럭키 포인트**
- 럭키 컬러: 네이비, 그레이 (전문가 느낌)
- 럭키 아이템: 플래너, 계산기, 전략 노트
- 럭키 넘버: 1, 8
- 럭키 플레이스: 스터디카페, 집 책상, 혼자 있는 공간

**오늘 하면 좋은 것**
- 중요한 프로젝트 마무리
- 투자/재테크 결정
- 경쟁력 높이는 공부
- 목표 달성 전략 짜기

**오늘 피하면 좋은 것**
- 즉흥적인 결정
- 다른 사람 의견에 휘둘리기
- 멀티태스킹 (집중이 핵심!)

**오늘의 응원 메시지**
오늘 당신의 판단력과 집중력은 최고 레벨입니다. 계획한 대로 움직이면 분명 좋은 결과가 있을 거예요. 혼자만의 승부, 조용한 성공을 만들어보세요. 당신의 전략이 빛을 발하는 날입니다!

#### 유형 4: IDE - 예상치 못한 행운 운

**오늘의 전반적 운세**
오늘은 직관을 믿으세요! 갑자기 떠오른 아이디어, 우연히 만난 사람, 예상치 못한 제안이 행운으로 이어질 수 있어요. 계획에 없던 변화가 생겨도 당황하지 말고 흐름을 타보세요. "이게 될까?" 싶은 것도 일단 시도해보면 의외로 잘 풀릴 수 있는 럭키비키한 날입니다!

**세부 운세**
- 연애운: 예상치 못한 고백/연락 가능성! 직감적으로 끌리는 사람에게 다가가보세요.
- 금전운: 뜻밖의 수입이나 할인 혜택. 복권/이벤트 응모도 나쁘지 않아요!
- 건강운: 즉흥적인 활동(댄스, 새로운 운동)이 스트레스 해소에 효과적!

**오늘의 럭키 포인트**
- 럭키 컬러: 옐로우, 오렌지 (밝고 활기찬 톤)
- 럭키 아이템: 새로운 것, 번개모양 악세사리, 행운의 코인
- 럭키 넘버: 7, 9
- 럭키 플레이스: 처음 가보는 곳, 우연히 들어간 가게

**오늘 하면 좋은 것**
- 즉흥적인 외출
- 새로운 시도 (첫경험 환영!)
- 복권/이벤트 응모
- 직감 따라 움직이기

**오늘 피하면 좋은 것**
- 지나친 계획 세우기
- 기회를 의심하고 놓치기
- 안전지대에만 머무르기

**오늘의 응원 메시지**
오늘은 우주가 당신 편입니다! 갑자기 생긴 기회를 놓치지 마세요. "이게 맞나?" 싶어도 일단 Go! 당신의 직감이 오늘은 특히 날카로워요. 예상치 못한 행운이 당신을 기다리고 있어요!

#### 유형 5: OSL - 인간관계 꽃길 운

**오늘의 전반적 운세**
오늘은 사람을 만날수록 좋은 날입니다! 대화하는 사람마다 좋은 에너지를 주고받고, 협력이 잘 되며, 인맥이 재산이 되는 하루예요. 혼자 고민하지 말고 주변에 도움을 요청하면 기꺼이 손 내밀어줄 거예요. 네트워킹, 소통, 협업이 빛을 발하는 날입니다!

**세부 운세**
- 연애운: 친구의 소개팅 제안 수락 추천! 기존 관계는 대화로 더 단단해져요.
- 금전운: 협업 프로젝트, 공동 투자 좋은 날. 혼자보단 함께할 때 더 큰 수익!
- 건강운: 친구와 함께 운동하면 동기부여 UP! 같이 하는 활동 추천.

**오늘의 럭키 포인트**
- 럭키 컬러: 스카이블루, 민트 (소통의 컬러)
- 럭키 아이템: 명함, 스마트폰, 귀여운 문구류
- 럭키 넘버: 2, 5
- 럭키 플레이스: 카페, 모임 장소, 네트워킹 이벤트

**오늘 하면 좋은 것**
- 밀린 연락 답장하기
- 모임 참석
- 새로운 사람 만나기
- 협업 제안 받아들이기

**오늘 피하면 좋은 것**
- 혼자 집에만 있기
- 연락 무시하기
- 배타적인 태도

**오늘의 응원 메시지**
오늘은 당신의 매력이 빛나는 날이에요! 사람들이 당신과 함께 있을 때 편안함과 즐거움을 느껴요. 적극적으로 소통하고, 관계에 투자하면 예상보다 훨씬 큰 보상이 돌아올 거예요. 함께할 때 더 강해지는 당신!

#### 유형 6: OSE - 로맨스 기운 폭발 운

**오늘의 전반적 운세**
오늘은 설렘 주의보입니다! 사랑의 기운이 넘쳐나서 어디를 가든 로맨스가 따라다녀요. 솔로라면 새로운 인연을 만날 가능성이 높고, 연인이 있다면 관계가 한층 더 깊어질 거예요. 감정을 솔직하게 표현하고, 매력을 마음껏 발산하세요. 오늘만큼은 주인공이 되어도 괜찮아요!

**세부 운세**
- 연애운: 폭발적 상승! 고백/데이트 신청하기 최적의 날. 설렘 가득한 하루!
- 금전운: 자기 관리에 투자 추천 (외모, 패션). 매력 UP = 기회 UP!
- 건강운: 활력 넘치는 날. 에너지를 긍정적인 관계에 쏟으면 행복도 UP!

**오늘의 럭키 포인트**
- 럭키 컬러: 레드, 핫핑크 (열정의 컬러)
- 럭키 아이템: 향수, 립스틱, 하트 모양 악세사리
- 럭키 넘버: 2, 9
- 럭키 플레이스: 로맨틱한 카페, 공원, 야경 명소

**오늘 하면 좋은 것**
- 고백/데이트 신청
- 외모 가꾸기 (헤어, 메이크업)
- 로맨틱한 장소 방문
- 사랑하는 사람에게 마음 표현

**오늘 피하면 좋은 것**
- 감정 숨기기
- 무뚝뚝한 태도
- 외모 관리 게을리하기

**오늘의 응원 메시지**
오늘 당신은 사랑받기 위해 태어난 사람처럼 빛나요! 주저하지 말고 마음을 표현해보세요. 설렘은 용기 있는 자의 것! 오늘 하루만큼은 로맨스 주인공이 되어보세요. 당신의 매력이 세상을 홀릴 거예요!

**세부 운세**

- 금전운: 투자 타이밍 최적! 신중하게 분석한 후 과감히 도전하세요.
- 건강운: 에너지 넘치는 날. 활동적인 운동으로 건강도 재산도 챙기기!

**오늘의 럭키 포인트**

- 럭키 아이템: 지갑, 동전, 재테크 앱
- 럭키 넘버: 8, 9
- 럭키 플레이스: 은행, 증권사, 비즈니스 미팅 장소

**오늘 하면 좋은 것**
- 투자 결정 (분석 후 실행!)
- 협상/계약
- 부업 시작
- 재테크 공부 실전 적용

**오늘 피하면 좋은 것**
- 충동적인 소비
- 도박성 투자
- 기회를 망설이다 놓치기

**오늘의 응원 메시지**
오늘은 당신의 머니 럭이 절정입니다! 계산된 도전은 분명 좋은 결과를 가져올 거예요. 기회를 놓치지 말고, 적극적으로 움직여보세요. 당신의 논리와 추진력이 재물을 불러올 거예요. 오늘 밤 통장을 확인해보세요!

## 4. 점수 산출 로직

### 점수 계산 방법

1. **각 문항의 A/B 선택에 따른 점수 부여**
   - A 선택: 0점
   - B 선택: 1점

2. **차원별 점수 합산**
   - E축 점수 = Q1 + Q2 + Q3 + Q4 (0~4점 범위)
   - F축 점수 = Q5 + Q6 + Q7 (0~3점 범위)
   - M축 점수 = Q8 + Q9 + Q10 (0~3점 범위)

3. **H/L 분류 기준 (중앙값 기준)**
   - **E축 (에너지 방향)**
     - 0~1점: I (Inner, 내향)
     - 2~4점: O (Outer, 외향)

   - **F축 (운의 흐름)**
     - 0~1점: S (Stable, 안정)
     - 2~3점: D (Dynamic, 도전)

   - **M축 (감성 모드)**
     - 0~1점: L (Logic, 이성)
     - 2~3점: E (Emotion, 감성)

4. **유형 결정 (3축 조합)**
   - 3개 차원의 분류 결과를 조합하여 3글자 코드 생성
   - 예시:
     - E=0, F=1, M=0 → I + S + L → **ISL** (조용한 성장 운)
     - E=3, F=3, M=3 → O + D + E → **ODE** (대박 터질 운)

### 유형 분류 매트릭스

| E축 결과 | F축 결과 | M축 결과 | 유형 코드 | 운세 유형 |
|---------|---------|---------|----------|----------|
| Inner (I) | Stable (S) | Logic (L) | ISL | 조용한 성장 운 |
| Inner (I) | Stable (S) | Emotion (E) | ISE | 힐링 에너지 운 |
| Inner (I) | Dynamic (D) | Logic (L) | IDL | 전략적 승부 운 |
| Inner (I) | Dynamic (D) | Emotion (E) | IDE | 예상치 못한 행운 운 |
| Outer (O) | Stable (S) | Logic (L) | OSL | 인간관계 꽃길 운 |
| Outer (O) | Stable (S) | Emotion (E) | OSE | 로맨스 기운 폭발 운 |
| Outer (O) | Dynamic (D) | Logic (L) | ODL | 금전운 상승 운 |
| Outer (O) | Dynamic (D) | Emotion (E) | ODE | 대박 터질 운 |

### 점수 산출 알고리즘 (의사코드)

```
// 1. 사용자 응답 수집
let answers = [Q1_answer, Q2_answer, ..., Q10_answer]  // A=0, B=1

// 2. 차원별 점수 계산
E_score = answers[0] + answers[1] + answers[2] + answers[3]
F_score = answers[4] + answers[5] + answers[6]
M_score = answers[7] + answers[8] + answers[9]

// 3. 차원별 분류
E_type = (E_score >= 2) ? "O" : "I"
F_type = (F_score >= 2) ? "D" : "S"
M_type = (M_score >= 2) ? "E" : "L"

// 4. 유형 코드 생성
fortune_type = E_type + F_type + M_type

// 5. 해당 유형의 운세 결과 반환
return getFortuneResult(fortune_type)
```

## 5. 구현 시 고려사항

1. **시작 화면**
