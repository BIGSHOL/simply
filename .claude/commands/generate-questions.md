# 심리테스트 문항 생성

주어진 테스트 주제와 결과 유형에 맞는 문항을 AI로 생성합니다.

## 입력 정보

사용자 요청: $ARGUMENTS

---

## 실행 단계

### 1단계: 문항 설계 파라미터 확인

```yaml
테스트 정보:
  주제:           # 예: 연애 유형
  타겟 사용자:     # 예: 20대 여성
  결과 유형 수:    # 예: 6개

문항 설정:
  총 문항 수:      # 권장: 8-12개
  문항 유형:       # 리커트/선택/시나리오
  역문항 포함:     # true/false

스타일:
  톤앤매너:       # MZ 감성, 위트, 공감
  문항 길이:      # 짧음(20자) / 중간(40자) / 긴편(60자+)
```

---

### 2단계: psychology-content-specialist 호출

```
Task(
  subagent_type: "psychology-content-specialist",
  description: "심리테스트 문항 생성",
  prompt: """
  ## 테스트 정보
  - 주제: {주제}
  - 타겟: {타겟}
  - 결과 유형: {유형 목록}
  - 문항 수: {N}개

  ## 문항 설계 원칙

  ### 1. 문항 유형별 구성

  **정문항** (결과와 정방향 상관):
  - 문항 {N*0.7}개
  - 높은 점수 = 해당 특성 강함

  **역문항** (결과와 역방향 상관):
  - 문항 {N*0.3}개
  - 응답 신뢰도 검증용
  - 점수 역산 처리 필요

  ### 2. 결과 유형별 문항 매핑

  각 결과 유형을 측정하는 문항이 최소 2개 이상 있어야 합니다.

  | 유형 | 관련 문항 | 가중치 |
  |------|----------|-------|
  | {유형1} | Q1, Q4, Q7 | 1.0 |
  | {유형2} | Q2, Q5, Q8 | 1.0 |
  | ... | ... | ... |

  ### 3. 문항 작성 가이드

  **좋은 문항 예시:**
  - "주말에 갑자기 연락 온 친구, 당신의 반응은?"
  - "소개팅에서 첫인상이 별로인 상대, 어떻게 하시나요?"

  **피해야 할 문항:**
  - "당신은 외향적인 편인가요?" (직접적, 재미없음)
  - "사람들과 어울리는 것을 좋아하시나요?" (뻔함)

  ### 4. 선택지 설계

  **리커트 척도 (5점)**
  1. 전혀 아니다
  2. 아니다
  3. 보통이다
  4. 그렇다
  5. 매우 그렇다

  **이지선다 (A/B)**
  - 명확히 다른 두 선택지
  - 둘 다 매력적이어야 함
  - 정답이 없어야 함

  **시나리오형**
  - 구체적인 상황 제시
  - 2-4개 행동 옵션
  - 각 옵션이 특정 유형과 매핑

  ## 산출물

  1. 문항 목록 (번호, 문항, 유형, 선택지, 점수 매핑)
  2. 문항-유형 매핑 테이블
  3. 역문항 처리 가이드
  4. 점수 계산 로직
  """
)
```

---

### 3단계: 문항 검증

생성된 문항을 다음 기준으로 검증:

```
검증 체크리스트:
□ 모든 결과 유형에 대응하는 문항 존재
□ 역문항이 전체의 20-30% 포함
□ 문항 길이가 일관적 (±10자)
□ 사회적 바람직성 편향 최소화
□ 모든 선택지가 선택될 가능성 있음
□ 중복되거나 유사한 문항 없음
□ MZ 감성에 맞는 표현 사용
```

- **선택지**:
  1. {선택지1} → {점수}점
  2. {선택지2} → {점수}점
  ...

### Q2. {문항 텍스트}

## 문항-유형 매핑

| 결과 유형 | 관련 문항 | 가중치 |
|----------|----------|-------|
| {유형1} | Q1, Q4, Q7 | 1.0 |
| ... | ... | ... |

## 점수 계산

```python
def calculate_score(answers: list[int]) -> dict:
    # 역문항 처리
    reversed_items = [3, 6, 9]  # 예시

    for i in reversed_items:
        answers[i] = 6 - answers[i]  # 5점 척도 역산

    # 차원별 점수
    scores = {
        "차원1": mean([answers[0], answers[3], answers[6]]),
        "차원2": mean([answers[1], answers[4], answers[7]]),
        # ...
    }
    return scores
```
