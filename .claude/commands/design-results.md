# 심리테스트 결과 유형 설계

기존 테스트의 결과 유형을 새로 설계하거나 개선합니다.

## 입력 정보

사용자 요청: $ARGUMENTS

---

## 실행 단계

### 1단계: 테스트 정보 확인

다음 정보가 필요합니다:

1. **테스트 ID 또는 이름**
2. **현재 문항 목록** (있는 경우)
3. **원하는 결과 유형 개수**
4. **결과 스타일** (유형/레벨/스펙트럼)

---

### 2단계: 결과 유형 설계

#### 유형 분류 방식 선택

| 방식 | 설명 | 예시 |
|------|------|------|
| **카테고리** | 명확히 구분되는 유형 | MBTI (16유형) |
| **스펙트럼** | 연속적인 척도 | 외향 ←→ 내향 |
| **레벨** | 단계별 분류 | 스트레스 고/중/저 |
| **조합** | 다차원 조합 | 2x2 매트릭스 |

---

### 3단계: result-analysis-specialist 호출

```
Task(
  subagent_type: "result-analysis-specialist",
  description: "결과 유형 설계",
  prompt: """
  ## 테스트 정보
  - 테스트명: {테스트명}
  - 문항 수: {N}개
  - 결과 유형: {M}개

  ## 요청 사항
  1. 결과 유형 정의
     - 각 유형의 이름 (캐치하고 기억에 남는)
     - 핵심 특성 (1-2문장)
     - 상세 설명 (3-5문장)
     - 강점/약점
     - 조언/팁

  2. 분류 로직
     - 점수 계산 방식
     - 유형 판정 기준
     - 경계 케이스 처리

  3. AI 프롬프트
     - 결과 생성용 시스템 프롬프트
     - 개인화 변수 정의
     - 톤앤매너 가이드

  4. SNS 공유용 콘텐츠
     - 한줄 요약 (30자 이내)
     - 해시태그 제안
     - 공유 이미지 컨셉
  """
)
```

### 4단계: 콘텐츠 검증

psychology-content-specialist와 협업하여 검증:

```
Task(
  subagent_type: "psychology-content-specialist",
  description: "결과 콘텐츠 검증",
  prompt: """
  ## 검증 항목

  1. 심리학적 타당성
     - 각 유형이 실제 심리학적 근거가 있는가?
     - 문항과 결과가 논리적으로 연결되는가?

  2. 균형성
     - 모든 유형이 긍정적 측면을 포함하는가?
     - 특정 유형이 "나쁜 결과"로 느껴지지 않는가?

  3. 변별력
     - 유형 간 차이가 명확한가?
     - 대부분이 하나의 유형에 몰리지 않는가?

  4. MZ 감성
     - 표현이 재치있고 공감 가는가?
     - 공유하고 싶은 결과인가?
  """
)
```
